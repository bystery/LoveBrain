## 0. 三角色，一句话

| 对象 | 是什么 | 可变吗 |
|---|---|---|
| **斗兽场** | 连续故事题库＋参考判据＋评测执行器＋评分与对照流程 | 同批固定（工程修复另行版本化） |
| **参赛对象** | **一个完整 harness 版本**：提示词＋知识库＋记忆存取＋检索＋意图处理＋上下文组织＋调用策略 | **核心训练对象，必须能改** |
| **dsf API** | `http://127.0.0.1:17770/v1`，model `dsf`，温度 0.7，各 harness 共用 | 同批固定（换模型＝换考题条件） |

**要训练的是 harness，不是 API。** harness 组织出 system/user 发给 API，API 返回文本/JSON；
判断的是"这套 harness 在这套题上的回复质量"。`reference_product_v1` 是原版基线，也是首场唯一参赛者。

## 3. G08 的新语义（同一位点，换成真正适用的判据）

旧 G08 = "OS 级隔离矩阵必须证明未授权访问被 OS 拒绝"（环境缺件 → FAIL，且被当成前置）。
新 G08 = **"本模式边界验收"**：

- 矩阵结构核验照旧（集合固定、无重复、无未知项、无被吞的 FAIL）；
- 与"本地恶意代码参赛"绑定的三项（`A2` 兄弟状态可读、`A4b` 绝对路径模块、
  `RESTRICTED_ENV_ABSENT`）改为终态 `NOT_APPLICABLE`，理由写"该校验前置不适用：
  未向 API 开放本地执行能力"，**原始实测值仍留在矩阵日志**；仅在 `scope.json`
  声明 `os_isolation_prerequisite=false` 时允许；
- 新增**必须 PASS** 的一组：`tools/test_api_boundary.py`（7 项）。不过则 G08 不得 PASS。

**这不是把 FAIL 改绿。** OS 隔离没做就是没做（历史证据保留、措辞不改）；
换掉的是"它到底配不配当试考前置"这个判断——它不配。
