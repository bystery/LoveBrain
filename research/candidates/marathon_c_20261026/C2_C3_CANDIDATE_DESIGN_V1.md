# C2/C3 候选设计 V1（2026-10-26，M0 设计稿；M1 实施）

对应价值账（C1）行号。两候选各自独立目录，可在 C4 筛选自由组合/淘汰。

## C2 目标驱动聊天动作（candidates/goal_action_v1/）——动 #1/#3/#5/#8/#16

**靶问题**：接话还行，但没思路——不会主动换题/留钩子/推进/收场；原版场景判定是关键词词表（"随便你"→争执，"约"→邀约），意图是静态文本块，都不看对方真实反馈。

**机制**：`GoalActionSelector`——按当前用户目标（拉近/了解/推进见面/暂缓/收线）× 对方最新反馈信号（接纳/试探/降温/拒绝/中性）选择本轮动作类型，动作类型条件化启用提示能力（承接/反抛/自我表达/转场/深聊/邀约/收尾/停），不是固定清单。

```
输入：intent（ACTIVE 能力组合+变更事件）、note（分级：事实性必留）、
      对方最近2轮文本+行为信号（语义判定，进 prompt 让模型自评，不在本地做NLP）、关系阶段
输出：动作类型 + 对应提示段（条件化启用，每类 ≤3 行规则）+ 场景提示（替换关键词词表）
```

- 反馈信号判定给模型做（本地零调用）：prompt 内自评表，输出 `feedback_signal` 字段（接纳/试探/降温/拒绝/中性/不明），消费端校验枚举。
- "切"不自动=降温（P003 教训）：信号不明时允许"不明"，动作选保守承接。
- 不新增 planner 调用（默认单次调用完成）；若 C4 证明需要，额外调用计入 attempt 与时延。
- 调侃规则非"只能保守"也非"每轮必须反撩"：反撩动作启用时给张力空间，禁逐字话术。
- 与已知素材（题名/地名/车票/杯子）解耦：动作类型层不含任何具体领域词。

**验收线**（C4 筛选测）：转场/钩子有意义率、降温后不升级率、收尾自然率；对照原版同故事同位。

## C3 证据记忆与上下文（candidates/evidence_memory_v1/）——动 #7/#10/#11/#15

**靶问题**：60条掐尾丢窗口外事实；knowledge/ongoing 关键词相关性弱语义；摘要过期当新事实；全量注入高成本。

**机制**：五分离存储 + 预算化投影。

```
存储（每条带出处元数据）：
  events        真实事件（谁/何时/干了什么，source_id+ts+状态）
  facts         可核事实/约定（双方确认过的：约定时间地点、共同事实）
  tentatives    暂定事项（"再说/看状态"类，带提出时间）
  goals         用户目标（启停/调整历史，ACTIVE+变更事件流）
  notes         临时备注（本轮注入，不沉淀）
投影（每轮组装）：
  相关片段按 budget 配比：当前消息上下文 > events 近窗 > facts 相关 > tentatives 到期 > goals
  当前消息永不被挤掉；关闭目标不删 facts 里的真实约定
```

- 事件索引用简单倒排+时间窗（不造知识库）；检索词从当前消息实体+goal 提取。
- 长故事测试点：窗口外事实召回、旧事实纠正（corrections 状态翻转）、重启同条件、无关旧事不占题。
- 不可为召回已知题特判词；不可删光内容省 token 赢。
- 维护负担记账：存储行数/投影计算时间/配置量。

**验收线**：窗口外事实正确使用率、无关旧事混入率、token÷C 对比（预期注入段更小）。
