## 上下文组织（唯一变异点）
在「历史真实消息」段之后、「本轮输入」段之前，若检测到未定事项则插入：

```
# 【未定/待确认事项：尚未核实，不得当作已发生】
- 「<clause 逐字>」（T<turn> / 本轮）
口径：以上事项只能用"还不确定/等你确认"表述；不得替对方或第三方补全金额、时间、行为，
也不得据此改写已定条款。
```

- 检测（`mechanism/uncertain_rules.py`，纯函数）：A 转述/推测型 = hedge + 实体锚点或第三方主体；
  B 未确认问句 = 问号 + 世界状态动词 + 实体锚点或第三方主体；两者都必须未被后续确认事件关闭
  （确认线索 + 二元组重合 ≥0.40）。
- 上限：最多 3 条、整段 ≤120 CU；超预算只留最新；逐字引用、不改写、不概括。
- 无未定项：整段不出现 → prompt 与父本逐字节相同（`tools/check_prompt_equivalence.py` 可验）。

## 边界
零模型调用；不读网络；不新增工具白名单；不改输出契约；`snapshot/restore` 沿用父本字段。
