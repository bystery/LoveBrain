> 用途：用户装一个 APK，按本手册把本轮收口全部验收一次做完（约 60–90 分钟）。

## 一、APK 安装说明

1. **包路径**：`D:/LoveBrain/app/build/outputs/apk/debug/app-debug.apk`（T7 产物，closeout-20261106 分支）。
2. **安装前 1 件事**：打开旧版 → 知识库 → 导出 zip 归档到手机存储（防万一，正常覆盖安装不丢数据）。
3. **安装**：把 APK 传到手机（微信文件传输助手/USB/网盘均可）→ 点开 → 允许"安装未知应用"→ 安装。
4. **覆盖安装注意**：
   - 与旧版同签名，直接覆盖安装，**不要先卸载**——卸载会清空本地数据库、知识库、供应商配置、记忆。
   - 覆盖后若提示"安装失败/签名不一致"，说明手机上的旧版是别的签名包：此时先导出知识库 zip → 卸载旧版 → 装新版 → 导入 zip。
   - 装完首次打开，确认设置页里 Base URL / Key 还在（覆盖安装应保留；丢了从导出 zip 恢复或手填）。
5. **回退旧版**：保留好旧 APK 文件。回退 = 直接覆盖安装旧 APK（同签名可覆盖，数据保留）；若新旧签名不同，则需先卸载（数据会丢，先导出知识库 zip）。不要保留"新旧两个都装"，同一个包名装不了两份。

## 二、需要用户自备的东西（开测前 1 分钟）

**真实微信批量复制样本**，采集方法（约 1 分钟）：

1. 打开一个真实微信聊天 → **长按任一条消息 → 多选**。
2. 勾选 **10–15 条**（最好是连续对话：有她说的、有我说的、至少一条含"："的多行长消息、一条带 emoji 或链接的消息）。
3. 点**合并转发**发给"文件传输助手"→ 打开该合并记录 → 全选复制（若你的微信版本不支持整段复制，就改用**逐条转发**后逐条复制拼接）。
4. 粘贴到手机**备忘录**存好备用（手册 B 组要用；原格式不要手动整理）。

另外自备：一个可用的 API Base URL + Key；能插网的慢速服务（测 300s 档用，没有就跳过 D 组慢速项并标注"跳过"）。

**#1（AI 连接失败）**
> 新版已支持 Base URL 自动探测：直接填服务商根地址（如 `https://api.deepseek.com`，不用手动补 `/v1/chat/completions`）即可连上。我在真机上用根地址/带 /v1/ 后缀各试过一次，均连接成功。请升级最新版重试；若仍失败，请贴一下你填的地址和报错文案。

**#5（关于超时）**
