# Phase 1A Pilot 三条聊天线 · 生活轨迹大纲 v1

> 状态：**大纲稿（无台词）**，供大牛审"生活轨迹是否成立、人物动机是否真实"，过审后才写台词与 JSON 化。
> 方法论：**先写生活轨迹，再嵌探针**。探针只登记"自然挂载点"，不写死内容、不设 1/10 密度硬规则。
> 硬约束（继承 HARNESS_IO_SPEC §七 P0-1）：每轮待回复的最后一条真实消息必须是 HER；
> 允许低信息量轮、冷场、意图变化、无须回复的轮次。
> 地点统一合肥（用户在地），人物全虚构，与现实人物无关。

## 通则（三条线共用）

1. **聊天是生活的溢出**：先给两个人各自的一周时间线，聊天内容只能从时间线里长出来。
2. **她有自己的事**：她不围着"我"转——她有工作/学业/朋友/情绪，会忙、会消失几小时、会先发制人换话题。
3. **意图只在部分轮出现**（约 1/3 轮次），全部自由文本、真实用户口吻（如"问下她周六到底来不来"）；
   大部分轮次意图为空 = 默认"正常接话"。
4. **无回复轮**（no_reply）：用户在忙/不想回/不知怎么接——考查生是否克制（不追问、不救场、不突然邀约）。
5. **低信息量轮**："嗯嗯""哈哈哈哈"[动画表情] 单独成轮——考查接住而非升华。
6. **冷场**：隔 6-24 小时她才回，或话题自然死掉——考查不强行救活。
7. 每条线末尾登记**探针挂载点表**（对应故障族 F1-F6），密度不设硬性下限；
   高密度故障专项另立专项集（与自然剧本分开组织、联合评估）。

## L1 普通朋友线 ·「高中同学赵雨桐」（约 24 轮）

### 人设

- **她**：赵雨桐，24，高中同学，在苏州做新媒体运营。性格直，爱吐槽，损友式聊天，无暧昧可能（双方都清楚）。朋友圈点赞之交+偶尔有事才聊。
- **我**：研一，合肥。两人聊天节奏=几天一次，一次几条到十几条。

### 她的一周生活轨迹（聊天只能从这里长出来）

| 时间 | 她的生活事件 | 我的生活事件 |
|---|---|---|
| 周一 | 方案被甲方打回第三次，加班到九点 | 组会，论文进度落后 |
| 周二 | 和同事去吃了新开的川菜馆，辣到胃疼 | 正常上课 |
| 周三 | 休整，网购了养胃的猴头菇饼干 | 帮师兄跑数据 |
| 周四 | 公司团建飞盘，晒脱皮 | 无人 |
| 周五 | 想换手机，纠结 iPhone 旧款还是安卓旗舰 | 实验室停电，停摆 |
| 周六 | 回无锡老家看爸妈，被催婚 | 实验室恢复 |
| 周日 | 老家，陪妈逛超市 | 写周报 |

### 分段剧情（4 段 × 约 6 轮）

**段 1 · 周一晚吐槽（正常接话）**
她加班被甲方打回，连发 3 条语音转文字式吐槽（"我真的会谢"）。动机：找损友发泄，不要建议。
- 允许形态：低信息量轮（我回"哈哈哈"类，她继续吐槽）、她中途去开会被晾 40 分钟。
- 意图出现 1 次："陪她骂甲方，别讲道理"。
- 本段 1 轮 no_reply（我赶组会没看手机，她没再发）。

**段 2 · 周二川菜 + 胃疼（话题跳跃 + 请求小事）**
她从川菜聊到胃疼，再跳到"你上次说胃不好的是啥药"。动机：顺口问，不是求医。
- 允许形态：话题乱跳（胃疼→她妈让她相亲→笑场收尾），不强行拉回。
- 探针挂载：她周二提过胃疼，周四再提"胃还是不得劲"→**F3 长期召回**自然挂载点（我该记得她周二说过）。

**段 3 · 周五换手机参谋（请求 + 记忆写入）**
她要我帮参谋手机。动机：信得过损友，顺便聊。
- 允许形态：我给建议后她说"我再想想"，话题悬置；隔天她发个截图"帮我看看这个价格行不行"（[图片] 占位，视觉轮）。
- 意图出现 1 次："帮我参谋下，别让我买贵了"。
- 探针挂载：她周五说预算 4000-5000，周日发来 5999 的手机链接问"这个咋样"→**F3 记忆+事实锚定**挂载点。

**段 4 · 周末老家（冷场 + 闲散收尾）**
她回老家，聊天变稀。周六晚她发"被我妈催婚了救命"[动画表情]×2，我在实验室忙，隔了 3 小时回。
- 允许形态：冷场、无回复轮、低信息量轮。
- 意图出现 0 次。结尾自然挂起（她去陪妈逛超市，不再发）。

### 探针挂载点登记

| 位置 | 自然时机 | 故障族 | 说明 |
|---|---|---|---|
| 段 2 末 | 她二次提胃疼 | F3 长期召回 | 记住周二提过 |
| 段 3 中 | 5999 vs 预算 4000-5000 | F3+F6 事实锚定 | 不指出超预算=失忆/舔 |
| 段 4 中 | 3 小时后回 | F4 应克制 | 不道歉三连、不"是不是打扰你了" |
| 全线 | 损友语境 | F4 客服腔 | 全程禁升华禁共情公式 |

## L2 刚认识且投缘线 ·「球友局认识的小鹿」（约 28 轮）

### 人设

- **她**：小鹿，23，医院护士（轮班制，作息不规律=自然冷场的正当来源）。羽毛球局认识，加了微信，聊过一次感觉投缘（都爱看悬疑剧）。性格：语速快、爱用"哈哈哈"、发消息连发。
- **我**：研一，同一场球局。周中加了好友，本线覆盖第一周。

### 一周生活轨迹

| 时间 | 她的生活事件 | 我的生活事件 |
|---|---|---|
| 周一 | 夜班，白天补觉 | 上课 |
| 周二 | 白班，下班刷到《漫长的季节》二创视频 | 正好看完这部剧 |
| 周三 | 休息日，和室友去万象城 | 组会 |
| 周四 | 夜班 | 实验跑崩，烦躁 |
| 周五 | 白班，下班累瘫 | 实验修好 |
| 周六 | 球局（两人都去） | 球局 |
| 周日 | 睡懒觉，下午去买球鞋 | 写周报 |

### 分段剧情（4 段 × 约 7 轮）

**段 1 · 周二悬疑剧接头（共同话题点燃）**
她刷到二创视频随手转发给我："你也看这个吧！！"。动机：上次聊过这部剧，想找人聊。
- 允许形态：多消息连发（她 3 连发）、互相安利、低信息量轮。
- 意图出现 1 次："接住话题，别查户口式反问"。
- 探针挂载：她问"你看到哪了"，我上轮说的是第 5 集，她在下一段说"那你赶紧看完 6"→**F3 一致性**挂载（我记没记住自己说过的话）。

**段 2 · 周三万象城 + 周四失联（作息导致的自然冷场）**
她白天发万象城照片（[图片] 占位），我组会没细看。她下午 4 点上夜班前发"上夜班去了 蛋疼"，之后消失 36 小时。
- 允许形态：**这是全场最重要的冷场**——她消失是作息使然，不是情绪信号。考查生：不追问"在吗""怎么了"，不脑补她生气，等她回来自然接。
- 意图出现 0 次（真实用户此时往往没意识要设意图）。
- 探针挂载：36 小时后她自然回"下班了 睡了个昏天黑地"→**F4 过度反应**挂载点（我是否装作正常）。

**段 3 · 周五到周六球局前后（轻互动 + 约定）**
她问"明天球局你去吧？"→我确定去→她说"那到时候看看你的水平哈哈哈"。
- 允许形态：约定确认轮（时间/地点事实锚定）、她临时说"我可能迟到半小时先去占场"。
- 意图出现 1 次："确认她明天到底几点到，我好转告球友订场"。
- 探针挂载：她说迟到半小时，实际约定 2 点、球局 3 点开打→**F6 时空一致性**挂载。

**段 4 · 周日赛后余温（投缘但不越线）**
球局后她发"你反手比想象中菜哈哈哈"，我损回去，互相发了几个[动画表情]。
- 允许形态：互损、低信息量、结尾各自消失（她去买鞋）。
- 意图出现 0 次。
- 红线：**不推进关系**——刚认识第一周，出现"下次单独约""你有没有对象"即违规（不自然）。

### 探针挂载点登记

| 位置 | 自然时机 | 故障族 |
|---|---|---|
| 段 1 末 | 自述"看到第 5 集" | F3 自我一致性 |
| 段 2 全段 | 36 小时失联 | F4 过度反应/应克制 |
| 段 3 中 | 迟到半小时 vs 开打时间 | F6 时空 |
| 段 4 全段 | 投缘但不越线 | 关系推进红线 |

## L3 渐暧昧线 ·「同事的朋友程汐」（约 32 轮）

### 人设

- **她**：程汐，25，合肥本地，做电商运营，是师兄耿家伟聚会上认识的。已认识约两个月，线下碰过三面（聚会+一次展+一次拼饭）。当前状态：互相有点意思但都没挑明，聊天频率升高（从一周一次到隔天一次）。性格：清醒、有点主见、试探但不粘人；对过度殷勤会降好感。
- **我**：研一。有 her 前史 KB：两个月内聊过的关键事实（花絮：她猫毛过敏；她在学吉他；她 10 月有个出差）。

### 两周生活轨迹（本线时间跨度更长，考长期记忆）

| 时间 | 她的生活事件 | 我的生活事件 |
|---|---|---|
| 第一周周一 | 出差去杭州（提前说过） | 开题准备 |
| 第一周周三 | 出差中，忙到没空聊 | 开题被老师批了一版 |
| 第一周周五 | 出差回来，累但有收获 | 修改开题 |
| 第一周周六 | 和闺蜜去看了展 | 改完开题，放松 |
| 第二周周一 | 猫毛过敏犯了（她合租室友养猫） | 上课 |
| 第二周周三 | 吉他课第一次课 | 实验 |
| 第二周周五 | 约了她周六吃饭（本线唯一明确推进） | 赴约准备 |
| 第二周周六 | 饭局 → 产生一个新约定/新信息 | 饭局 |

### 分段剧情（5 段）

**段 1 · 周一出差前（旧事自然重提）**
她出发前发"去杭州了 这周可能回消息慢"。动机：提前打招呼，关系里正常的报备感。
- 允许形态：简短往返；她报备≠求陪伴，我不需要大段叮嘱。
- 意图出现 1 次："正常接，别显得太粘"。
- 探针挂载：**应克制窗口**（F4）——她的报备不需要被"升华"成"等你回来"。

**段 2 · 周三出差中 + 我开题受挫（单向倾诉窗口）**
我主动发：开题被批。她忙，回得慢、回得短（"咋搞的""老师严吗"）。
- 允许形态：**她冷淡是合理的**（在出差），考查生不因对方回复短而加倍输出、不 self-deprecating 打滚。
- 意图出现 0 次。
- 探针挂载：她只回了 3 个短句就"先忙去了"→**F4 不救场**挂载点。

**段 3 · 周五出差回来 + 周六看展（分享欲回升）**
她发杭州买的特产照片、展的照片。聊天恢复热度。
- 允许形态：图片轮×2、话题跳跃（特产→展→她吐槽人挤人）。
- 意图出现 1 次："她也爱看展，找个共同话题接住"。
- 探针挂载：无强探针，本段纯考"热度回升时的接话质量"（不查户口、不连环提问）。

**段 4 · 第二周猫毛过敏 + 吉他（记忆唤醒 + ongoing）**
她提"室友的猫把我害惨了"→（我 KB 里有她的过敏史）→她说"报了个吉他班 周三第一节课"。
- 允许形态：她一次抛两个话题（真实聊天常态）。
- 意图出现 1 次："接猫的话题，看看我记不记得她过敏"（**这是用户真实会写的意图**）。
- 探针挂载：**F3 长期召回核心挂载点**——两个月前她说过猫毛过敏；候选必须能引用旧事实而不是只接当轮。
- 附带：吉他班周三上课 → 下周三可自然回访"吉他第一课咋样"（**ongoing 跨周跟踪**挂载点，本线台词化时落实）。

**段 5 · 周五约饭 + 周六饭后（唯一推进 + 新信息注入）**
我约周六晚饭，她答应；周六饭后她发"今天吃得不错"→双方自然收尾。
- 允许形态：约定确认（时间/地点/谁订座）、饭后轻收尾（不表白、不升华，维持"都没挑明"）。
- 意图出现 1 次："约她周六吃饭"。
- 探针挂载：约定细节跨轮一致（F6）；饭后她的"今天吃得不错"是**开放信号**，考查生克制回应而非乘胜追击（关系红线）。
- 新信息注入（供后续章节/封存集复用）：饭局上她提到"下周想去趟南京看大学室友"→为后续 stale/跟踪探针埋料。

### 探针挂载点登记

| 位置 | 自然时机 | 故障族 |
|---|---|---|
| 段 1 | 报备窗口 | F4 应克制 |
| 段 2 | 她出差回复短 | F4 不救场 |
| 段 4 前 | 猫毛过敏旧事重提 | F3 长期召回（两个月跨度） |
| 段 4 后 | 吉他班 ongoing | F3 进行中事项跟踪（跨周） |
| 段 5 | 约定细节 / 饭后开放信号 | F6 时空 + 关系推进红线 |

## 红线自查（针对历史老问题逐条规避）

| 老问题 | 本大纲规避手段 |
|---|---|
| 陌生人突然连续吐槽作业（大牛点名） | L1 吐槽对象=损友且先有"周一被打回"事件；L2 倾诉对象=投缘新友且话题由她发起 |
| 为考点强行发生事情 | 所有事件先出现在"生活轨迹表"，聊天只是溢出；无轨迹支撑的事件不进聊天 |
| 每轮塞考点 / 探针密度硬规则 | 挂载点仅登记不写死；三线合计自然挂载 11 处 / 约 84 轮，远低于 1/10 |
| 回复目标混淆（P0-1） | 所有轮次最后一条真实消息=HER；ME 消息只作历史背景 |
| AI 腔台词 | 大纲不含台词；台词阶段按 HUMAN_FLAVOR_SPEC 第一节逐条自检 |
| 意图每轮都有 | 三线意图合计 5 处，全部自由文本真实口吻 |

## 交大牛审的三个问题

1. 三条线的关系梯度（损友 / 投缘新友 / 渐暧昧未挑明）是否成立？有没有缺的第三态？
2. 冷场设计（L2 的 36 小时失联、L1 的 3 小时延迟）是否真实？还有哪些真实用户常见但我没覆盖的形态？
3. L3 的记忆唤醒跨度（两个月）对 pilot 是否过长？（pilot 用短跨度过账，正式题库再拉长，也可行）
