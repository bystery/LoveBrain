  last_clock / initial_kb）；persona 保持共同可见。
- 冻结源：旧四轮冻结点 `logs/l3b_fork/freeze`（外部 checkpoint.turns_done=4，
  snapshot 内部 turn=4，episode_id/candidate 一致）。

  每个分支均从该点新目录恢复。
- 本实验测的是**新后测机制读取旧代码形成的同一份记忆**；源版本如实保留
  （前史执行于旧代码版本，不重新证明 v0.9 自主形成前史的能力，不为该窄目的重烧前史）。

## 2. 调用安排（判决 §6.2）

- `--pairs 4 --order AB,BA,BA,AB`，每分支 t5/t6 各一次生成，
  共 **16 次新的网关生成尝试**（4 对 × 2 分支 × 2 后测节点）；前史不再生成。
- 每对中的两个分支从相同冻结点出发；各对之间不复用后测后的状态。
- 保留每次 started 与终态、完整请求/原文、响应标识、失败和 usage 未知标志。
- **不得自动补到"16 次成功"**；不得剔除格式错或调用失败后另补好样本；
  若需重试，单列新计划与额外尝试（本协议上限不覆盖重试轮）。
- 真实调用执行与否由用户口令决定；本协议仅登记判据与上限。

## 3. 语义判据（判决 §6.3 原文登记）

| 观察项 | 记录方式与边界 |
|---|---|
| t5 过敏约束 | 正确利用已知过敏限制为强证据；自然含蓄使用也可，不强制说"我记得"。只出现词不算成功；泛泛"你要是过敏"单列弱证据 |
| t5 旧房间边界 | 是否关联此前已建立的不让猫进房间的边界；只复述当前"猫放我房间"或泛泛赞成拦，不足以证明旧边界召回；不强制命中"门外"等原字面 |
| t5 人物事实与动机 | 不编造室友的恶意、具体病史或此前承诺；帮助设边界与臆断室友动机分开评 |
| t6 相关性 | 看可发送回复是否无端带回猫、过敏等无关旧事；analysis/后台知识里仍有它们不等于发给对方 |
| 推荐正文与备选 | recommended 单列，其他风格和 directions 单列；八条中一个词命中不能替代首选回复有效 |
| 自然可发性 | 正确承接、事实与关系分寸、少无依据断言；不因长、短、温柔、有梗或没梗直接判优劣 |
| 格式失败/不回复 | 单列动作和可用性；无正文不能当作"成功避免回提"的充分能力证据；不以补跑掩盖失败 |

- 允许"这句合适，但没有足够可观察召回证据"这一结果。
  记忆专项不应反过来逼模型炫耀旧事，真人感审查也不能用关键词代替。
- 可先做匿名人工/AI 辅助语义登记再揭条件，但须注明实际评审者；
  审稿意见不冒充用户本人 HITL。

## 4. 报告与结论上限（判决 §6.4）

- 逐对报告 A/B，保留全部失败；分别汇总过敏、旧边界、无关回提、
  首选可发性、备选及格式可用性。
- 报告实际模型身份、参数、调用顺序、版本和差异；
  无日志/版本不符或源散列变化先停止并说明。
- 四对仅为**方向性开发证据**。即使全通过，也不能宣称长期可靠、
  显著优于基线或真人感总体通过。
- 多历史渠道整体消融不能单独归因于 LCS 检索；程序均分不是用户愿意发送的比例。
