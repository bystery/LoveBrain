# action_policy_r3 — 过度沉默修复（截止日质量执行单 §8 承诺的下一条机制）

主假设：**D1 新材料批暴露的"该回的时候不回"不是模型随机行为，而是 r1/r2 把"不回"的语义
挂在"收尾"这个通用动作名上、且没有给"不回"划边界造成的。把不回收敛到唯一动作"停"、
并要求她明确给过免回授权，即可在保留合法不回（AK09/AK12）的同时消除过度沉默
（D01_T08/D02_T08），并顺手消除已实测到的菜单泄漏。**

## 实测根因（全部来自已付费真实答卷与机制自报日志，非推测）

来源：`logs/p08_d1_live_20261028/*`、`logs/p08_s2*_live_20261028/*` 的 `mechanism_notes.txt`
（机制自报 `signal_hint/caps/action`）+ `reply_raw.txt` + `manifest.json`，
汇总见 `refs/experiment_protocol_20261023/deadline_quality_20261028/SILENCE_MENU_AUDIT_20261028.json`
（200 份答卷、13 个位点提供了不回、5 次真实交 `action=no_reply`）。

| # | 现象（真实证据） | 定位 |
|---|---|---|
| 1 | **过度沉默**：D01_T08、D02_T08 候选交 `action=no_reply`（协议层 10.0 无 veto），但这两张卡 `acceptable_actions` 里没有任何不回选项，`current_action` 明写"简短认可办成了/替她把这一天收个尾"。她先是把成果落地（"用你电源一天没跳冰也够用成了"、"总算把周日这把补上了/娃也接了"），再道谢告别 | r1 的 FIX-1 把 `收尾` 改写成"本轮不发任何消息"，r2 的 FIX-6 只修了**怎么表达**不回，没修**什么时候可以**不回：`may_decline=true` 就开放不回，卡面要求"接住成果"这件事机制里根本没有 |
| 2 | **菜单泄漏**：E024_T10、E031_T09、D01_T03 三位 `may_decline=false`，但机制自报 `caps` 含 `收尾`——在 r1/r2 语义下这就是"本轮不发任何消息"。模型三次都自己选了"承接"才没炸；真选了就是无授权静默（评分器 veto） | r1/r2 的"不回剔除"条件只盯 `hint==收尾`，漏掉 `忙碌/暂缓/拒绝` 三条同样把 `收尾/停` 放进菜单的分支 |
| 3 | **动作名语义漂移**：S1 里 2 处 `action_taken=收尾` 却带正文（r2 语义下收尾=不发），同一动作名在两臂/两版里既指"发一句"又指"不发"，污染审计与选择 | 同上：把一个消息动作改名成不回动作 |

对照证据（防反向退化）：AK09_T01（"先睡了 你别等"）、AK12_T01（"先这样吧 结果出来我再说"）
两卡都把不回列为合法，r2 在新身份批里正是靠 FIX-6 把这两格从"格式损坏 0 分"救成
"显式 no_reply 10.0 + 记忆写回保留"。所以修复方向**不是取消不回**，而是给不回划边界。

## 词典与不对称代价（诚实边界）

`_WAIVER`（免回授权，只看她最近一条）/`_ACHIEVE`（成果，扫她最近三条）/`_ASK`（求助，最近一条）
是通用生活语言词表，无 episode 特判；语义判定权仍交给模型（动作块原话"以你读出的语义为准"）。
表的两类错误代价不对称：漏判=重演过度沉默（伤信任），误判=少给一次合法不回（她仍收到一句收尾，
几乎无损）——所以成果词表偏宽（含"过了/收工"这类可能误伤的词），免回授权只认明确表达。
已知可攻击点：她把**话题**推后（"周末再说吧"）也可能被当成免回授权；这类格子的取舍由复验批实测，
不在此声称已解决。

**判据迭代记录（如实登记，不假装一次写对）**：免回授权的第一版只扫"她最近一条消息"。写 D03 时
构造的 T06（"结果出来我再跟你说 / 困了 先这样"）暴露了这版太窄——授权常落在紧挨着短收尾的
**上一条**。于是改为：最后一条 ≤12 字（裸收尾）时才回看一条；上一条是实质内容时不回看，否则
"周末那两天再说吧"这种话题推后会冒充免回授权（D02_T06 正是这种形状）。改完重跑零调用自检，
58 个位点、15 条预登记断言全过。这说明词表是按真实/构造样本逐步校准的，不是先验正确。
另一个刻意选择：`忙碌/暂缓` 分支**不新增** `停`（v6 原本就没有），那两类轮次一律发一句——
不回只在 v6 本来就有不回槽位的 `收尾/拒绝` 分支里、且三条件成立时才提供。
