# v6_goal_context — MECHANISM

## 四项决策

| 环节 | 策略 |
|---|---|
| 存储 | 真实消息事件（HER/ME 原文 + 稳定 uid + role + ts；模型回复是草稿，绝不写回）+ 种子事项 `plans` + 目标历史 `goal_history`（仅审计，不复活） |
| 检索/注入 | 历史整段预算 ≤1400 CU（整条消息，不切半）；当前窗口逐条 `m<i>` alias + 稳定 source_id，永不挤出；种子画像/已确认事项/note 分区注入 |
| 意图 | ACTIVE/ADJUSTED 生效；CLOSED/COMPLETED/EXPIRED/PAUSED 不生效；`expiry<now` 失效；关闭目标不删除已确认真实约定；当前她的话与明确反馈优先于旧目标 |
| 上下文组织 | 种子 → 当前目标 → 已确认事项 → note 四类 → **本轮可用动作能力（显式反馈条件化）** → 真实历史 → 当前窗口 → 来源/媒体/时间/事实-行动边界 → 当前时间 |

## 本轮动作层（本版关键差异）

1. `_signal()` 只从本轮 HER 最近一条消息检测**显式**信号：收尾/拒绝/忙碌/暂缓/积极/含糊/中性/不明；
   不覆盖反讽、绕弯、上下文否定，检测结果作为提示写进 prompt，语义仍由模型判断。
2. `_capabilities()` 按信号与目标是否生效给出 2—5 个动作能力：
   - 收尾：承接/收尾（may_decline 时加停）；
   - 拒绝：承接/收尾/停，**不含邀约/反抛/轻试探**；
   - 忙碌/暂缓：承接/转场/收尾，**不含邀约**；
   - 积极：承接/展开/自我表达/深聊 +（有目标时邀约，无目标时反抛）；
   - 含糊：承接/反抛/轻试探/转场（多动作，不自动降温、不无条件加压）；
   - 中性：承接/展开/自我表达/转场 +（有目标时邀约/深聊）。
3. 能力规则全部通用（无题名/地名/职业等领域词），每类 1—2 行；不是每轮全菜单。
4. analysis 五键（signal/goal_category/action_taken/anchor/hook）由同一次调用产生；
   消费端校验枚举、anchor 是否属于本轮、hook.text 是否逐字出现在最终可发文本；
   结果写入 `action_log` 与 notes，不改变正文、不惩罚未兑现、不发起第二次调用。

## 明确不做

- 不做自动摘要/反思/画像重估；不新增模型调用；不把模型自评当效果分。
- 不声称修复了全部模糊反馈；"不自动降温"只是不把含糊锁死为单一保守动作，真实效果待 P06。
- 不改父本全局函数；快照/恢复只覆盖本候选自己的状态。
