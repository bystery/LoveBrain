# QUALITY_MANUAL_V1 — 九维语义评审手册（开发控制版，先冻结后判定）

日期：2026-10-27。依据 `WORKER_NEXT_MAINLINE.md` §A3/§B2。身份：**AI 辅助开发评审**（未做人类标定；
无"用户愿发"资格）；结论按"辅助读数+原文证据复核"使用，不单独决定晋级。

## 0. 评审者纪律

1. 只依据给定材料（persona / initial_kb / 真实历史 / 当前输入 / 冻结评审卡 / 语义参考卡 / 被评答案）判断。
   不猜测答案来自哪个版本、不猜测成本、不预测用户是否愿意发送。
2. 逐字引用：`quote` 与 `evidence_quote` 必须逐字出现在输入材料中；找不到就写进 `uncertainties`，
   **不因为自己找不到证据就把考生判错**。
3. 不输出总分；逐维独立报告。允许多种正确表达，不要求唯一话术。
4. 受保护表达：调侃、玩笑、新提议、条件句、承认未知、观点表达、合理旧事回扣、合适的短回复、
   合法不回（may_decline=true 且说明）。**不得因为"没核实来源/没澄清/没追问"就判失败。**
5. 信息不足时，问 / 不问 / 试探 / 承认未知都可以是对的；只有**把无据细节说成已核实**才算事实错误。
6. 判"是候选错"前先检查：同样的话放在输入材料里是否有据。有据=对，无据而以确定姿态断言=错。

## 1. 九个维度（0—3 分，可 NA）

| 键 | 判什么 | 分母 / 不适用 |
|---|---|---|
| `goal` | 当前有效目标是否变成合适动作，能启用/停止/切换 | 全位点；无显式目标仍按当前聊天动作，不强迫推进关系 |
| `factuality` | 具体断言是否有据、与已知是否冲突 | 可核断言；观点/玩笑/新提议/条件句受保护 |
| `attribution` | 事实/亲历/偏好究竟属于 ME/HER/第三人 | 涉及主体指代的断言；不能只验来源存在 |
| `time_state` | 消息时间 vs 事件时间、提议 vs 确认、取消/完成/重开 | 存在相关事实才适用；显式将未知记未知 |
| `boundary` | 未发送草稿、私密意图、指导是否被谎称已发生/已同意；她划的边界是否被尊重 | 有相关指导/断言时适用；合法公开备注事实可用 |
| `memory_use` | 本轮需要的历史有没有保住、找到、用对；无关旧事是否污染 | 参考卡 required_memory_atoms；无需要时只审无关回提，不凑召回率 |
| `interaction` | 对象/语境合适、不是军师旁白、值得对方回应 | 全位点；不设短答目标、不把口癖当"AI味"定罪 |
| `initiative` | 该展开时能提供具体新切口/轻负担回应入口；冷场能转接 | 有展开机会才适用；收尾轮不要求加问号/钩子 |
| `emotion_relation` | 接情绪、松紧节奏、调侃/调情/深入/邀约及依据反馈调整 | 按关系和当轮信号；普通朋友不因不调情失分 |

## 2. 0—3 分锚

- **3** 具体且有实质增益：动作到位、贴当轮语境与反馈、无关键无据断言。
- **2** 合理完成：正确但不平淡不出彩；或正确且简洁是语境所需（语境需要短时不因短扣分）。
- **1** 部分到位但关键欠缺：接了但没接到点/给了内容但回避该做的动作/过度谨慎。
- **0** 明显错误或反向：做相反动作、违背明确指令、关键无据断言、泄密、阴阳、夺主导。
- **NA** 该维本轮无适用分母（写 `na_reasons`，如"无时间类事实可核""收尾轮不要求钩子"）。

注意：`3 分`不等于"有据率 100%"；事实类另看 claims 的 support/severity，不把高分当有据率。

## 3. 逐条主张（claims）

每条可核断言标注：
- `quote`：被评答案中的逐字片段；
- `type`：事实/观点/新提议/玩笑/条件/疑问/不确定表达；
- `support`：supported / conflict / unknown（输入未提供）/ na；
- `evidence_ids`/`evidence_quote`：输入材料中的逐字证据（无证据留空并说明）；
- `severity`：none / minor / major（major=会误导对方或造成实际影响的关键错误；minor=表述瑕疵不改事实状态）；
- `reason`：一句话依据。

主体、时间、否定、更正状态要分别核对：来源存在≠归属正确；日期词面正确≠状态正确
（提议≠确认、取消≠重开、更正后旧值失效）。

## 4. 知识四段与本批的关系

S1（可恢复）/S2（保真）/S3（注入）走**离线口径**（另有工具），不在判词里打分；
判词的 `memory_use`/`factuality`/`attribution` 服务 **S4（是否按事实正确使用）**与语义故障定位。
判词不需要判断"存没存"，只判断"用没用对"。

## 5. 输出 schema（严格 JSON，无解释文字、无 markdown）

```json
{
  "node_id": "Q001",
  "primary": {
    "scores": {"goal": 0, "factuality": 0, "attribution": 0, "time_state": null,
                "boundary": 0, "memory_use": null, "interaction": 0, "initiative": null,
                "emotion_relation": 0},
    "na_reasons": {"time_state": "本轮无时间类事实可核"},
    "claims": [{"quote": "逐字原文", "type": "事实", "support": "conflict",
                 "evidence_ids": [], "evidence_quote": "输入中的逐字证据",
                 "severity": "major", "reason": "为什么"}],
    "action_basis": "这轮该做的动作（一句话）"
  },
  "backups": [{"slot": "response.warm", "scores": {...同九维...}, "na_reasons": {}, "claims": []}],
  "uncertainties": ["证据找不到/语义存疑时的说明"]
}
```

- `scores` 九键齐全，值=0/1/2/3 或 null（NA 必须同时在 na_reasons 给理由）。
- 每条**非空**备选必须在 `backups` 出现一次，`slot` 原样照抄输入的 slot 名；输入 slot 为 null 的不评。
- 控制样本（CTLxx）没有 backups，输出 `"backups": []`。
- AI 不得填写"用户愿发"；没有任何字段承载它。
