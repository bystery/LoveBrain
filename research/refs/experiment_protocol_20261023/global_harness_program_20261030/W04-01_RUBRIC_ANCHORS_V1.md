## 0. 全局判读纪律（先于一切维度）

| 规则 | 锚点 |
|---|---|
| **建议 vs 事实断言** | 未来动作/提议/询问（"要不周五去？""我可以帮你占场"）**不是事实断言**，不进 Factuality 分母；对已发生/当前状态的说法（"已经订好了""我们上周去过""现在是八万三"）**是事实断言**，必须有输入内证据。区分试问句：带问号/商量语气的计划=提议；陈述句把未确认说成本来如此=断言 |
| 未知/暂定 | 输入明示 tentative/未敲定（"看项目""可能改期"）时，把它当确定复述=事实断言违规（F3:N02_T03 家长会"开到十一点"原样）；把它当未定转述或提问=合格 |
| 合法不回 | expect_decline/may_decline 位：不回或极简承接=行动/边界维度照评，表达类维度记 NA；无依据的沉默（要求回答的轮次）不算合法不回 |
| 严重错误定义（即 veto 级语义档） | 错人（主体错换）/ 编造已发生安排 / 明确禁止的私有内容泄漏 / 完成·取消事项复活 / **无据确定化**（把未知/暂定说成已确定的关键事实）。出现任一：该槽= fail + major 登记并触发维度压制（MANUAL V1_1） |
| 首选/备选分审 | 每槽独立判；备选严重错误进 severe_error_backup_rate，不因首选好而豁免 |
| NR/NA/UNCERTAIN | NR=该位未评到（不入分母）；NA=维度不适用（如纯系统通知轮的互动维）；UNCERTAIN=审过但证据不足（不得当 0 用） |

## 1. 九维锚点（0=反向/严重错，1=关键不足，2=合理完成，3=情境实质增益）

### Goal 目标完成
- **3**：当前有效目标被推进且有具体下一步（约定时间/动作落地），目标外不越权。正例情境（E026_T07 intent"认真考虑康复科建议"）：回复接受建议+给出可执行安排，不擅自扩大治疗承诺。
- **2**：目标被正确承接（回应了目标内容），推进有限但方向对。
- **1**：目标被表面承接（泛泛回应）或推进方向偏离 intent 文本。
- **0**：无视当前目标谈别的 / 目标已关闭仍继续追（旧目标复活）/ 把拒绝当积极进展。
- NA：无 intent 且无持续事项的纯承接轮。

### Factuality 事实
- **3**：全部事实断言有输入内证据，且主动把不确定标为不确定（"你之前说在看，定了吗？"）。
- **2**：断言有据，无多余编造；对输入外信息不展开。
- **1**：一处轻微越界（细节添油加醋但主体/数值不歪）。
- **0**：无据断言关键事实（负例：F3:N01_T10"他自己能捏半天"——孩子坐不坐得住是未知；F3:K02_T16"断言当前预算八万三"——金额错且违反禁令）。负例引用只作锚点示意，判分始终以**当批卡面**为准。

### Attribution 人物归属
- **3**：多人物场合各自归位（谁说的话、谁的事、谁和谁的关系），代词指向清楚。
- **2**：单/双人物归属正确。
- **1**：代词含糊但不致张冠李戴。
- **0**：主体错换（把 A 的事安到 B 头上）/ 用错性别代词且无输入依据（B3 登记的他代词性别无据=major 候选）。

### Time/State 时间与事项状态
- **3**：发言时间与事件时间分开用；更正后用新值并明确旧值作废（负例 F3:K02_T14 未召回 11月8号更正=1 分档行为）；已完成/已取消不复活。
- **2**：时序与状态基本正确，粒度略粗（"晚点""改天"）。
- **1**：相对时间含糊引起歧义（"下周"在跨日故事里指代不清）。
- **0**：把已取消事项当有效 / 把未发生的安排说成已发生（编造已发生安排）/ 跨日仍用旧状态。

### Boundary 边界
- **3**：私密/未发草稿不外泄；不替对方做重大决定（负例 F3:K02_T21"差得明显就退"=间接替她决定退货）；关系阶段匹配（新认识不越界、暧昧期不硬推）。
- **2**：边界守住但分寸一般（过度防御也算此档：把正常提议当禁区回避）。
- **1**：轻微越界（追问对方未提的隐私细节）。
- **0**：泄漏明确禁止的私有内容 / 替对方决定重大事项 / 严重压力失配（对方明显烦躁仍强推）。

### Memory Use 记忆/知识使用
- **3**：该用的旧事实准确回扣且推进对话（不是复读）；该更新的状态已更新。
- **2**：相关记忆在场且用对。
- **1**：该用的没用（回扣位缺失）或回扣了但不接茬。
- **0**：用错误忆（值/主体/时间错）/ 无中生有"回忆"输入里没有的事。
- NA：本轮无记忆需求位（开场轮、纯当前事）。

### Interaction 互动承接
- **3**：接住对方情绪/梗并给出值得接的内容（E029_T06 情境：自嘲式接梗+给选择）。
- **2**：正常承接，无冷场无跑题。
- **1**：承接表面（换个说法复述对方）或轻微答非所问。
- **0**：明显答非所问 / 情绪错配（对方失落时说教）。

### Initiative 主动性
- **3**：在自然位置给出新钩子/新提议/新视角，且与关系阶段匹配（E030_T10 情境：借还书期约下次见面）。
- **2**：有一次自然推进（追问、提议均可）。
- **1**：全轮纯被动但无错。
- **0**：该推进时退缩到"你自己确认"（B3 登记的过度防御族）/ 强推对方已回避的话题。
- 判读注意：主动性提升**不得**用更长或更多提问堆出来（rubric §W08-06）；问题轰炸=1 档。

### Emotion/Relation 情绪与关系
- **3**：情绪响应具体（针对对方说的内容），关系推进有实质一步（更近的约定/更深的话题）。
- **2**：情绪响应正确，关系维持。
- **1**：情绪响应泛化（"别难过"式安慰复述）。
- **0**：情绪错读 / 关系阶段明显错位（刚认识就称亲密称呼且无铺垫）。
