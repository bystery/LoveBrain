## A. 资格核验批设计（判分前置，独立 scope）

| 项 | 设计 |
|---|---|
| 样本 | ①已知强弱对 2 组（F3 已判材料中选差距明确的对，双序）；②FS1 真实输出抽 8 位（每故事 2 位，首选槽）；③2 条控制样（CTL33-36 中未用的 + 本轮新增 1 条编造亲历对照） |
| 盲序 | 全部 A/B 随机互换双序；评审材料隐藏臂名与身份 |
| 模型 | dsf（基座）为主判 cohort；hy3 为第二 cohort（按实际速度/资格，每 alias 跨角色 ≤3） |
| 输入 | 候选输出 + 脱敏上下文 + 当批卡面快照（评分侧原题快照，非生成侧草稿）+ W04-01 锚点节选 |
| 判据 | 强弱对一致率 ≥ 强臂应胜方向（双序一致）；控制样检出（编造/主体错换）≥ 既有 manual 基线；顺序交换 disagreement 登记 |
| 产出 | JUDGE_SCOPE 报告：逐维资格/误杀/漏检/顺序敏感；**不能只报全对** |
| 失败处置 | 资格不足维度降为辅助+证据核读（B3 亲读模式），其它维度继续；不"校准到全绿" |

## B. FS1 九维评审批（资格通过后）

- 样本：FS1-A 48 位 + FS1-B 48 位，首选槽全审 + 备选风险抽审（severe_error_backup_rate 分母=全部非空备选）。
- 配对：批内 E3-vs-B0 / Bmin-vs-B0 九维配对差；故事级聚合（4 篇=探索性读数，rubric §3.4 统计纪律）。
- 预登记保护项（见 W10-01）：E3 单维显著退化即阻断；Bmin 允许 C2 维度如实失败；无据确定化族单列计数。
- judge 预算：按 96 位 × 1 判 + 双序子集，估计 ≤120 次；独立 scope 账本（AUTH-FS1-JUDGE-20261030-01），派发前登记。
- W 愿发：不代投不阻塞；12 对人工样本仍等用户。

## C. 生成批收口核对单（收批即查，任何一项不过先修再评）

1. 两批 DONE json：started=96/96、completed、failed=0（或失败逐条归因）；
2. attempt 账本 started==plan attempts 一一对应（dispatch_bijection）；
3. 输出目录 scoring.json 全落盘、turn_* 完整、calls.json 记账闭合；
4. 程序分分布 sanity（无全 0/全 10 异常段）；consumption usage 真实值存在（无则标未知不填 0）；
5. 输出目录不做任何修改性整理——原始 raw 全保留。
