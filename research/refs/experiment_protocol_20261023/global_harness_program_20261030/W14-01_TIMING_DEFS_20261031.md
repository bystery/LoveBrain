## 三个关键诚实性保证（实测在案）

1. **首个内容 ≠ 首个可发送**：G1 轮 `first_usable_ms=null, usable_reason=not_verified,
   preview_contract_status=preview_only_unverified, requires_full_payload=true` ——未做消费校验
   就如实标注，不把 preview 冒充可用。
2. **usage 不伪造**：`usage_source=api_usage`（stream_options 已扩白名单并送出，cache_hit/miss
   字段在位留空）——与模块注释"未批准时不许把这种批当费用可比正式批"的历史口径相比，
   当前批 usage 是 API 实回值，费用可比性成立。
3. **分段不猜因**：headers(4s) vs first_content(27s) 分离记录——排队/推理/传输成因留分段证据，
   不用秒级日志相减。
