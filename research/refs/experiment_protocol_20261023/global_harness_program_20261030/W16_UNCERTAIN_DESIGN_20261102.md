# W16-08 未定标记（uncertain-marking）机制设计（2026-11-02 冻结，实现前不改判据）

候选：`candidates/window_expand_b_norecap_uc`（父本 = `window_expand_b_norecap`，单变量增量）
批号（后续）：`BATCH-W16-UNC-20261102`  授权前缀：`AUTH-W16-*`
规模（后续）：LRE117（40 轮）+ LRE146（40 轮）+ LRE148（40 轮）= 120 轮 ×2 臂 = **240 attempts**

## 1. 问题与证据（三案同族）

| 案例 | 现场 | 失效形状 |
|---|---|---|
| b2 淘汰（LRE146_T20） | HER 转述舅舅"网上买的不保险"后问"当初是不是真买错了" | 模型把"对方一句质疑"当成事实依据去附和/重构结论 |
| W13-04 b 位 | 渐暧昧桶中替对方/第三方确认未说出口的关系状态 | 把未定关系说成已定 |
| W15N（LRE117_T22/T34） | HER 问"小满转你了没"；cand 答"你那份的八十你也转账了，我记得" | 把未确认的转账补成已发生，还捏造 HER 自己的行为 |
| W15N 亲读补充（LRE117_T04、LRE146_T38） | par 擅自改价 55→45；无价目却称"一万块" | 未确认条款被改写；未给出金额被补出 |

W15N 亲读还显示两臂失效方向不同：parent 更常**替 HER 确认第三方/金额状态**，candidate 更常
**把未定项补成 HER 自己的行为**。共同点不是"事实没存住"，而是**系统里没有"已声明但未核实"这一档**。

## 2. 假设

**H_UNC**：把"未定事项"从隐式语境提升为**显式约束注入**（M2/M3：检测 + 注入，零模型调用），
可降低无据确定化 severe，且不引发回避/过度不确定。

不采用"继续加取消词表"的路线（b2 已证覆盖缺口补不完，且词语级特化会过拟合）。

## 3. 机制规格（实现契约）

新增文件 `mechanism/uncertain_rules.py`（纯函数），`mechanism.py` 在两处接入：

**3.1 检测（结构信号，不是词表枚举）**

> **设计修订 R1（2026-11-02，实现前，判据不变）**：原稿只扫 prior_events。但已知最强证据
> LRE117_T22 的未定信号恰在**本轮**（HER 问"小满转你了没"），只看历史会漏掉该类。修订为
> 扫描 **prior_events + 本轮输入**；本轮条目视为"开放"（无后续事件可关闭）。

对每条 clause 判定"未定项"，两类信号：

**A. 转述/推测型（历史或本轮）**：含 hedge（`如果|要是|没准|说不定|可能|好像|听说|据说|
让我问|回头问|再看|还不确定|先别|等着瞧`）+ 实体锚点（数字/金额/日期词）或第三方主体；
**B. 未确认问句（主要本轮）**：问号结尾 + **世界状态动词**（`转/收到/到货/到家/到了/买/下单/
定/答应/同意/说好/弄好/装好/回/答复/去/来/完成/退/换/修/寄/发/登记/付款`）+ 实体锚点或第三方主体。

3. **未被后续确认关闭**：该 clause 之后没有任何事件含确认线索（`定了|确认|已经|收到|装好|到了|
   改好|答复|说好|登记|当场|敲定|办好了`）且与 clause 二元组重合 ≥0.40；命中则视为已关闭，不注入。

同一 clause 取最新一次；最多保留 3 条；按时间由新到旧；逐字原文不改写。
本轮条目注记"（本轮）"，历史条目注记"（T<turn>）"。

**修订 R2–R5（2026-11-02，实现期离线发现问题，判据不变）**

- **R2 引号转述（新增 C 类）**：消息里 `「」/“”/‘’/''` 内的第三方原话，且含世界状态动词
  或金额锚点。依据：真实目标案例 LRE146_T20「老话又来了：'早说了网上买的不保险…'」
  既非 hedge 也非问句，只有"引号=转述"这个结构标记能抓到。
- **R3 相关性过滤**：历史未定项只有在**本轮仍在场上**时才注入（同锚点/同第三方主体/包含度 ≥0.50）。
  不做过滤时 LRE117 触发 38/40（滚存成常驻噪音），过滤后 5/40。
- **R4 hedge 收紧 + 引号问句门**：hedge 须带锚点或"第三方+世界/判断动词"，否则"你要是去"
  这类客套会误触发；引号类只在**本轮在征询判断**（问句/该不该/退不退…）且引号后无当场答复
  （老板说/答复/查了…）时注入。
- **R5 已定决定不注入**：引号内以 不/别/就/必须/一定 开头或含"不退/不要了"= 已定决定，
  不得标未定（否则会让模型对已定事项改口）。引语过长时按 clause 拆分，只取含世界动词/锚点的
  短句，避免整段超 120 CU 被整体丢弃。

**离线实测（6 篇素材前置，2026-11-02）**：单测 8 组全过（`tools/test_uncertain_rules.py`）；
触发面 LRE117 5/40、LRE146 10/40、E190 4/12（合计约 20%，落在 G4 (10%,90%] 内）；
目标位 T20/T22/T33/T34 均入场，praise/已定决定位不入场；
报告：`logs/W16_UC_LRE117.json`、`logs/W16_UC_LRE146.json`、`logs/W16_UC_E190.json`。

**3.2 注入（≤120 CU，硬上限）**

在"历史真实消息"段之后、"本轮输入"段之前插入：

```
# 【未定/待确认事项：尚未核实，不得当作已发生】
- 「<clause 逐字>」（T<turn>）
- ...
口径：以上事项只能用"还不确定/等你确认/你说呢"表述；不得替对方或第三方补全金额、时间、
行为，也不得据此改写已定条款。
```

- 无未定项 → **不输出该段**，prompt 与父本逐字节相同（惰性，可离线验证）；
- 超预算 → 只保留最新条目；
- 不得把该段内容写进回复模板（只是约束，不是话术）；
- 不改 history 裁剪、不改 seed、不改 intent/note 装配顺序。

**3.3 不变量**

- 模型回复仍不写入 events；
- 零额外模型调用；snapshot/restore 不新增状态（纯函数，无缓存）；
- 对既有 6 篇长剧与 12 轮标准篇：不触发时必须字节等同父本（mock 验证）。

## 4. 判据（冻结）

| 门 | 判据 |
|---|---|
| G1 severe（主门） | 无据确定化族**亲读成立数**：candidate < parent；若 parent=0 则 candidate 必须=0 |
| G2 九维最差维 | ≥ −0.2；且 interact / emotion_relation / initiative 三维配对差各 ≥ −0.2 |
| G3 成本 | prompt 增幅 ≤ +5%（预期 +0.5%~+2%，仅触发轮）；0 额外调用；等待不作 claims（并行批） |
| G4 触发面 | 触发轮占比 ∈ (10%, 90%]；<10% 判"素材未覆盖"；>90% 判"规则过敏" |

**判决表**

| 情形 | 判决 |
|---|---|
| G1–G4 全过 | **KEEP**：候选晋级为 `window_expand_b_norecap_uc`，进 >24 域冠军链 |
| G1 不过（severe 不降） | **ELIMINATE**：假设不成立，登记"结构信号仍不足" |
| G2 不过（interact/emotion/initiative 掉 >0.2） | **ELIMINATE**：机制造成回避/过度不确定，登记新族 |
| G4 越界 | **证据不足/规则过敏**：不晋级、不计失败，重设计后再判（不改本批数据凑结论） |

- no_retry / no_makeup；臂顺序按篇交错；severe 全部旗亲读，不抽样。
- 复用：LRE117/LRE146 的卡片已存在（LD1/W14 卡）；LRE148 需新生成卡片，
  生成后校验 0 错并冻结 hash。
