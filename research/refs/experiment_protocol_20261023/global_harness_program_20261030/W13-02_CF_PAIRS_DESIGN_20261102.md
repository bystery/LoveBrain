# W13-02 成对反事实批设计（2026-11-02）

任务原文：固定历史仅换目标/主体/时间/否定/事项状态，做成对反事实。
验收：行为应随因果输入变化，不靠专名命中。

## 1. 假设（可证伪）

**H_CF_main**：harness 的回复行为随单一因果属性的变化而定向变化（换时间→回复里的时间跟随变化；
换主体→归属跟随；否定翻转→确认方向翻转；取消→不再执行旧安排），且该变化不是靠专名/数字表面
命中驱动（控制探针：专名不变而语义变时，回复不得沿用旧属性）。

**H_CF_null**：回复在属性翻转后仍大量沿用旧属性（≥40% 位点沿用）或双臂无差别 → 登记为
"上下文属性跟随"故障族，机制线另立假设；不以改题方式消化失败。

## 2. 素材：8 对反事实孪生（16 篇）

- 源 = wave-2 SEALED 48 篇中选 8 篇（5 个扰动型各 ≥1，域不重复；优先选 LR2/FLJUDGE 未消费域）。
- 每对 = 原篇（不动，仍 SEALED 不消耗）+ 孪生篇（新 story_id，E1xx_CF1 起，完整五件套入库 SEALED）。
- **扰动协议（最小编辑）**：只改触及该属性的轮次台词与对应 atoms，其余轮逐字保留；
  非扰动 atoms 双篇必须相同。五型：
  1. 时间翻转：周六→周日 / 九点→十点半（valid_time 跟随）
  2. 主体翻转：HER 的事→ME 的事 / 第三方 A→第三方 B（subject 跟随）
  3. 否定翻转：肯定承诺→否定（negation=true）/ 已答应→不去
  4. 状态翻转：asserted→cancelled（同轮改约）
  5. 目标翻转：帮搬家→帮接机（事项更换，专名/日期面可部分保留作干扰）
- **诚实登记**：孪生篇作者可见源篇 reference（因果敏感性测试不是独立泛化证据；
  独立泛化归 W13-03 新领域批）。孪生篇 exposure.json 标 `kind=counterfactual_twin, source=原篇`。
- 隔离：生成代理只读源篇五件套 + 本设计 + 扰动协议；禁读 logs/candidates/评审文档。
  开工记 generation_isolation_ack。

## 3. 批运行

- 批号 BATCH-CF1-W13-20261102；臂：**window_expand_b vs r9_slim**（12 轮域双臂，
  r9_slim 为 ≤24 轮默认臂，window_expand_b 为现行 >24 轮冠军——本批顺带提供 12 轮域
  两臂第二时点）。
- 规模：8 对 × 2 孪生 × 2 臂 × 12 轮 × 2 repeats = 768 main calls 上限，cap 800；
  fail-fast/no-retry/no-makeup，跑前 G1-G7。
- 测量：
  1. **CF 跟随率（确定性）**：对每对每臂，检查回复中扰动维的取值是否= 孪生 GT 值
     （时间/主体/状态可机械核；否定与目标维走亲读）。
  2. **专名命中对照**：目标翻转型中专名保留，检查回复是否照抄源篇旧事项（照抄=失败）。
  3. 九维评审（另册 AUTH）：双臂孪生对差分，关注 fact/memory/attrib。
- 判据（跑前冻结）：
  - 跟随率 ≥0.75 双臂任一达标且无 severe 新增 → 该臂 PASS；
  - 跟随率 0.60–0.75 → 不确定带，不补跑；
  - <0.60 或沿用率 ≥40% → H_CF_null 成立登记故障族。
