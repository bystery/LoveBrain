## 缓存字段核账

- usage 字段含 cache_hit/cache_miss 槽位（W14-01 已确认在案）；**全量普查 80 文件均为
  (False, False, 'api_usage')**——dsf 网关未回填缓存统计，非 harness 丢失。
- 结论：**缓存失败消耗=不可核算状态**（无数据源），任何"缓存命中省 X"的断言在当前网关
  下不可做。字段保留，网关若回填即自动生效。

- r9_slim 每 OK 结果 −241.6 tokens（−3.8%）——与 prompt 字符节省比例一致，质量平局下
  即为净成本收益。
- 提示前缀缓存角度：r9_slim 的瘦身发生在 system 静态资产与 user 回扣块——system 前缀字节
  变化会破坏网关侧前缀缓存（若有）；因网关不回填缓存统计，此效应不可见也不可计。登记为
  网关侧观察项。
