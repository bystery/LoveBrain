## 4. 预算

- 管理帽 16,384 attempts（不可变）；每批独立 scope ledger（logs/auth_budget/AUTH-*.jsonl）；
  授权链根：AUTH-GLOBAL-CONTINUOUS-20261030-01（用户地狱级常设授权）。
- 预注册：每批 plan sha256 + 判据 + 保护项先于执行冻结（LONGPROBE_*_PREREGISTRATION.json）。
- 零派发闸：plan attempts != 授权 attempts 拒发（G1 曾被拦，已修授权推导）。
- 评审另册计数（judge 调用单独记账）。

## 5. 统计与判决纪律

- 配对设计：story×turn 级配对差；配对胜/负/平计数；平局保持现任。
- 判决链：第一轮→勘误→复算→第四轮全量核算（E3 复职→r7 升格）；任何 ELIMINATE 需
  跨批复现（r7 severe 0/96 vs E3 3/96，2/2 批）；单批不淘汰。
- 自动回退触发器（冠军在位期）：保护维 ≤−0.5 / severe 增多 / veto 率 ≥3 倍且 n≥192。
- **统计口径教训**：随机 veto/基座 roll 会产生 3/192 级噪声——差在噪声内不判优劣
  （E3 3.8% vs B0 3.1% 先例）。
