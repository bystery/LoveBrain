## 结果

1. **对话事实召回：两臂完全持平 28/28**。所有可定位断言轮的对话原子（age 0-2）在两臂介质中全部可命中。
2. **4 个 initial_kb 原子在两臂均判 miss——介质定义伪差**：种子事实在两臂共有的【画像/初始事实(种子)】块中，不属于对话记忆介质的差异。剔除后两臂真实 miss 均为 0。
3. **窗口深度检验：12 轮 FS1 故事内 Bmin 窗口不滑出**。T12 时窗口 ~1250 字符仍逐字保留 T01/T03 对话原文（4 故事 8 探针全 HIT）→ Bmin 的架构性失忆风险（事实滑出窗口）在本数据集**未触发**。
4. **成本：E3 无召回增益却多花 ~16% 记忆上下文**。E3 每轮 = 窗口(~717) + 投影(~114) ≈ 831 字符；Bmin = ~717 字符。E3 投影行相对 stage2 原子集未匹配 40/113 行——其中大部分是引擎捕获但 stage2 未标注的内容与状态行（已更正/已完成），不必然是噪声，但确实是没有 stage2 背书的多余载荷。
5. **相关检索架构的真实差异化在三个本数据集未覆盖的域**：
   - 长程（>窗深）事实保留：longprobe 31 轮域 F1 保真 96.8%，但无 Bmin 头对头；
   - 状态簿记：E3 投影带 已更正/已完成/暂定/自动作废 标记；raw window 新旧断言并存，模型自行分辨——这正是 fabrication/severe 的暴露面（r7 supersede 引擎侧解决的同一问题域）；
   - 跨会话持久化：r1 store 文件级持久，Bmin 无。

## 裁定

- **短故事域（≤窗深）：Bmin 原文窗是更省的等效架构**——召回同、每轮少 ~114 字符、无簿记载荷。任何"相关检索投影"在这类对话里是纯开销。
- **冠军 r7_supersede（r1 系）保留**：其价值主张不在短故事召回，而在长程保留 + 引擎侧状态簿记 + 持久化；Bmin 未在这三个域被测量，无推翻依据。
- **下一代假设 r8（登记不构建）**：混合架构——Bmin 式原文窗 + r1 store 只投"状态变更行"（更正/作废/完成），不投常规事实摘要。预测：短故事域成本回到 Bmin 水平，长程/簿记域保留 r1 能力。W09 架构竞争可用 F1 保真协议 + 本工具直接测它。

## 方法论注记

- E3 臂 user 字段同样含【真实历史消息】窗口——单独测投影块会低估其介质；头对头必须按"窗口+摘要"组合介质计。
- 复合原子（一条原子合并两条事实）对投影的 bigram 匹配系统性低判；本数据集靠组合介质兜底后无残差，但更细粒度真值（逐事实而非逐原子）会让该偏差显形。
- 全程零模型调用：calls.json 落盘的完整 prompt + stage2 真值即可完成架构级对比。
