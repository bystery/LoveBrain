# v4_intent_context — 下一代意图与上下文候选（初稿，VERDICT §6-C）

**主假设**：当前目标的"作用域与上下文优先级"值不值得单独做进去。

**唯一相对 v0 的增量**：在"精简 system + 简单事件记忆"之上，只加一层目标作用域与上下文优先级规则；不改正在被比较的父本/v3，不复制后漂移，无额外模型调用、无题材词特判。

## 要回答的问题

- 把"当前目标"放进预算保护区、并让它可指导行动（而不只是 notes 一个标志/只调口吻），能否提升主动推进与接招质量？
- 关闭/切换目标后不污染、已确认事项不因关闭被删、也不自动复活旧目标——这些状态语义是否减少错误？
- 代价：prompt 组织复杂度、维护负担，以及是否引入新的越权（把目标复述成要发的话、谎称已同意）。

## 状态

**可运行初稿**。fixtures 只证明输入行为（启用/切换/关闭、目标进请求、行动指令、已确认事项持续、note 四类、草稿不写回），不证明"更会聊"。等本次 v3 真实对照结果出来后，再决定是否为本候选申请实跑；未获授权前不发起真实调用。

## 关系

- system：与 v3 同一份精简资产（本候选自带副本，`test_v4_intent_context` 断言 `build_system_prompt` 与 v3 逐字节相等）。
- 记忆：简单事件 + 种子事项（无多层 topic/ongoing/scene 摘要、无反思、无辅助生成）。
- 三方对照坐标：v3=精简system+原多层记忆；v0=精简system+简单记忆(公平输入)；v4=精简system+简单记忆+目标作用域/上下文优先级。
