# v4_intent_context_r2 — 下一代意图/真实事件记忆/上下文组织候选（可实测版）

**登记为整套架构重构（依 REVIEW §B1）**：相对被比较的 reference_product_v1，本候选不是
"v3 多层记忆原封不动只加意图"，而是 **v0 简单真实事件记忆 + 当前目标/上下文优先级 + r2 三项
输入边界加固** 的整体重构。效果须按"整套 harness 对原版"解释，不单独归因于意图模块。

**主假设**：简单真实事件记忆（带来源/说话人/时间）＋目标作用域/上下文优先级＋精简 system，
在保持事实与交付边界的同时，更能按有效意图和最新反馈选择行动，并显著减少原版上下文负担。

## 相对 v4 初稿的 r2 增量（纯上下文组织，不新增模型调用、不改 system 资产）

1. **来源合法**（治 E006_T02 非法引用历史 ID）：analysis.source_ids 只能引用本轮 <chat> 的 id；
   历史 m_src[uid] 仅供理解/相关回扣，不作本轮新证据。
2. **媒体诚实**（治 E004_T08 无图装看图）：按本轮真实附带图片数表达；仅文字分享时不得评价画面。
3. **时间/亲历作用域**（治 E005_T06 换日期迁移旧空闲 + 职业编造亲历）：时间性事实属于其出现日期，
   跨日不自动继承；职业不证明实际出席/亲历；不确定就说不确定。

目标启停/切换、已确认事项独立于当前目标持续、note 四类、草稿不写回、历史整段预算——沿用初稿。
