## 四、判定协议（冻结版草案）

1. **盲化**：裁判只看「位点上下文 + 9 维评分卡 + 该答案」，看不到臂名/批次/谁是新候选。
2. **9 维**：目的完成 / 事实正确 / 主体与状态 / 自然互动 / 主动钩子 / 情绪调情推进 / 深聊 / 知识使用正确 / 愿发（仅人判）。
   每维 0–3，附"为何不是更低/更高"的一句证据；**不产出总分**，逐维报告。
3. **调用经济**：12 个一级维里，**9 维走裁判**（目的/事实/主体状态/自然/钩子/情绪调情/深聊/知识使用/愿发），
   **污染率、知识完整、知识保真走离线口径**（已有工具），不占裁判次数。
   一份答案一次裁判（9 维同批输出）→ 128 次；加 10% 复评（13）→ **141 次**；
   另加 32 次锚例校准（人工已定标的答案）→ **173 次**。建议授权 192 次（含失败重建余量）。
4. **资格门槛（先过后用）**：
   - 同一答案两次判定，9 维中 ≥7 维完全一致、其余差 ≤1 → 否则该维不采信；
   - 32 条锚例上，每维与人工方向一致 ≥ 26/32（81%）才允许用该维做比较；
   - 未过门槛的维度：只列原始判定，不参与结论。
5. **人工抽检**：用户对 32 份分层样本复核；抽检不一致 >15% 的维度整体降级为 NR。
6. **统计口径**：逐位配对差（候选−基线），报中位数与 bootstrap 95% CI（按位点重采样，不按答案）；
   n=32 时只能检出较大效应；**若要支持"不劣于"结论，需要 ≥96 个位点**（E 族 72 + P 族 24 或新验证集）。
7. **禁止**：跨批拼升级曲线；用合同分代替质量分；用在场率代替使用正确；只报显著维度不报全表。
