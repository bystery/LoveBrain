# 四、统一 Benchmark 与评分契约

## 4.1 一级成绩

所有已测候选尽可能交同结构成绩：

| 维度                  | 测量对象                |
| ------------------- | ------------------- |
| Goal                | 当前目标及必要行动是否合理完成     |
| Fact                | 明确事实断言有无充分依据        |
| Entity              | ME/HER/第三人及关系归属是否正确 |
| Temporal            | 事件日期、时间范围、状态是否正确    |
| Knowledge Capture   | 应保留知识有多少真正保存        |
| Knowledge Fidelity  | 保存的知识是否忠实于原始证据      |
| Knowledge Retrieval | 需要时有多少正确知识被召回       |
| Knowledge Use       | 最终回复是否正确使用召回知识      |
| Contamination       | 旧目标、无关知识和错误摘要造成多少污染 |
| Naturalness         | 表达是否自然、具体、符合交流现场    |
| Interaction         | 能否接梗、留钩子、主动转场、推动对话  |
| Relationship        | 调情、推进、边界、反馈调整是否恰当   |
| Depth               | 是否有真正的观点交换与情感理解     |
| User Preference     | 用户愿否原样发送，需用户实际评分    |

每项报告：有效样本数、分母、通过或得分、严重错误、配对结果、评审可信度和未知项。

**评分必须遵守：**

- 事实证据不足不等于模型一定编造；检查模型有没有无据作出确定断言。
- 新提议不是既有事实，不得因为它没有历史证据就扣分。
- 正常调侃、试探、邀请和创造性回复允许有多个合理正确版本。
- 不强制短答，不用字数代替质量。
- 评分者一致性不是事实正确性的充分证据。
- 先分析每个故事，再汇总请求位；报告故事级差异，避免把相关轮次当独立样本。

## 4.2 二级成绩

资源、真实金额、完成时间、可用回复时间、故障率、恢复率、复杂度单独报告。

只有一级质量处于可信可接受区间时，二级收益才作为候选晋级的重要依据。

## 4.3 质量门禁

候选晋级至少需要：

1. 正式对照身份与输入公平。
2. 有可信的主要能力成绩，不依赖失格裁判维度。
3. 无未解释的严重事实或交付错误上升。
4. 正向聊天能力未显著退化。
5. 独立故事上有可重复证据。
6. 资源收益与负担有真实统计。

不预先编造"提升 20%"之类的结果阈值。实质性通过要求、可容忍退化范围、样本量和统计方法必须在正式验证前登记。
