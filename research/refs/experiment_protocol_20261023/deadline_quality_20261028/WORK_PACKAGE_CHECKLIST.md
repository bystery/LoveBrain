# 新工作包五问核销（一页，不是总计划）

任何新工作包动手前先填这五行。填不出来＝还没想清楚该不该做。
本文件只定义格式和一个已填样例，不替代当前执行入口，也不新增里程碑。

## 模板

| 项 | 要写什么 |
|---|---|
| 1 已有成果在哪 | 现有实现/结果/证据的**绝对路径**；没有就写"无" |
| 2 缺口是什么 | 可复现的现象 + 一手证据；区分"实现缺"／"质量证据缺"／"环境缺" |
| 3 复用什么 | 明确不重写、不重跑的旧资产（工具、答卷、账本、尺子）；默认复用 |
| 4 本次实际差分 | 新增/修改了什么（文件、函数、常量）；能给出哈希/行数更好 |
| 5 为什么必须新增调用 | 填数字。0＝离线完成，不需要授权；>0 必须写明实验问题、新身份、预算来源，禁止"为验证工程改动重烧调用" |

任务类型先归五类之一：已有成果复用／必要缺陷修复／修后复验／新假设实验／可避免重做。
只有后四类才安排工作；"可避免重做"必须给出为何不能复用。
