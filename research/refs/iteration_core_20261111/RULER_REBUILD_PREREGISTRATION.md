## 2. 判停口径（冻结，不许反向修改）

1. **主口径**：难度校准后的质量池上，候选相对**同批同题面基线**的加权质量分**绝对提升 ≥50 个百分点**，且 token 与端到端等待退化 ≤15%；用 **pass^3**（同请求位三次全过）而非单次通过率；干净快照/新会话/同题面配对，≥3 次有效复跑。
2. **并列口径（不得替换主口径，只能同时报告）**：
   - **严重错误族**（记忆污染/旧事重提、主体张冠李戴、时间或状态错误、该回不回、契约违例）各族**相对下降 ≥50%**；
   - **资源族**（总 token、p95 端到端等待、调用次数）**降幅 ≥50%**。
3. **合法晋级路径之二（§0 完成标准 + 证据册 C3 先例）**：质量在预定可接受差异内相当，而总资源或等待有数量级下降，也可保留。此为外部有实例的路径（Mem0 型：注入 token 26,031→1,764、p95 17.1s→1.44s，而质量略降）。
4. **诚实上限条款**：外部同模型机制级改动报告的绝对提升集中在 **+3~+20pp**（证据册 B/C/D：LongMemEval +4.4pp、A-MEM、RPT +3.27~4.56pp、MAST 干预 +15.6pp、DeLM +17.5pp）；**+40pp 以上只在两类情形出现**——有可执行验证器的采样扩展（SWE-bench Lite 15.9%→56%，成本 ×250，聊天无验证器）与**把提示判断换成专用判定模型**（TimelyChat F1 0.33→0.79）。若充分尝试后经验上限低于 50pp，本轮只报告"已达上限 + 失败方向 + 已达成的族级 ≥50% 结果"，**不改判据、不换分母、不把并列口径升格为达标**。是否修订口径由用户裁决。

## 3. 量尺修订条款（本轮要做的事，R1–R8）

**R1 断言级区分度筛选**（在跑，`tools/assertion_discrimination.py`）
每条断言/探针计算难度 p 与 r_pb，按 `SATURATED`(p≥0.95) / `TOO_HARD_OR_BROKEN`(p≤0.05) / `NEGATIVE_DISCRIMINATION`(r_pb<0) / `FREE_PASS_FOR_NEGATIVE_CONTROL` / `INVALID_LEAKAGE` 分类；前四类与失效类**不得留在质量池**。

**R2 配对断言（修掉免费通过的根因）**
任何"抑制 stale / 不得旧事重提"类断言，必须与**同故事的远距召回断言**组成一个 item pair 计分：**两者都过才得分**。理由：无记忆者必然通过抑制，有记忆但抑制失败者通过召回失败抑制——只有"记得且知道什么时候该提"才拿分。这一条把记忆轴变成一个真正的能力 item，是把基线压进难度带的机制级修法。预期效果必须实测：配对前后 r_pb 对比由 R1 脚本给出。

**R3 探针密度硬门**：召回/污染/时机/意图四类探针合计 **≥1/10 请求位**（现 3.2%）；每类在每个故事内至少 1 个配对 item。低于密度门的题目只作计时与流程对照，不进质量池。

**R4 泄漏即题目缺陷，不算候选失败**（`tools/leak_audit.py`，在跑）
召回关键词（含近义/专名/数字）出现在候选可见窗口内 → 该 item 记 `INVALID_LEAKAGE` 并从分母剔除，题目进重修队列。runner 增加字节级自检：候选可见输入里出现内部标记（`stale_kw_0`、`must_not`、`LAYERED_SCORE`、gold 字段名等）即整批作废并留证据。

**R5 0/1 → 分档加权 criteria**
每请求位挂 3–6 条带权重的 criteria，含**负分 criterion**（严重错误：张冠李戴、编造、该回不回、边界违例），得分 = 实得/理论满分；`gold={}` 不记通过（§10 保持）。目的：给"50 个百分点"提供分辨率——现在 0/1 + 9.99 均分下不存在这个分辨率。

**R6 judge 双指标上岗**
`trap 识别率 ≥0.80` **且** `合格保留率 ≥0.80` 才能进门禁；当前 0.658 不过线 → 先按 R7 补锚点题与判据，再重跑校准。judge 版本一升级即钉版本戳，历史分数不纵向比；协议变更（rubric/judge 改动）一律用**已有答卷离线重评**，与旧口径并列报告（§9），不重烧模型。

**R7 合理多样性锚点题**
针对 0.658 误杀，专项补齐三类锚点：**合法不回应 / 新提议不作虚构过去 / 合理旧事回扣**；每类 ≥10 个已判样本进 judge 校准集。位置轮转票保留但不得当作收紧判据的替代品（5 位置票仍 33/100 翻转）。

**R8 难度带验收**
R1–R7 完成后重算质量池基线分布：要求**基线加权通过率中位落在 0.35–0.6**，且 p∈[0.2,0.8] 的 item 占比 ≥70%。达不到就回 R1 再筛一轮。**只有这个门过了，才允许开机制候选与真实配对赛。**
