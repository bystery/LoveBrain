## 1. 候选改动（唯一主变量）

- 候选：`candidates/phase1_retr_idf`；父版本 `phase0_beta_single`。
- **唯一主变量 = 检索策略**：原始字符 LCS≥2 → **内容字 IDF 加权余弦，阈值 0.15**。
  assets/params 与父版本 sha256 一致（params `e215b718…` 双份相同）；
  写回策略、单阶段编排、memory-off 语义、快照格式逐行未动
  （同输入写回/快照字节一致由 `tools/test_retr_idf.py` C 组断言）。
- 策略构成（通用 IR 做法，**无任何针对猫/过敏/原题的词表**）：
  1. 通用时间指示词整词剥离（今天/明天/上周/改天…——历史事实中的相对时间是陈旧指称）；
  2. 通用停用字过滤（的了着呢吧…功能/话语标记 ~60 字）；
  3. 内容字集合 IDF 余弦（IDF 在本轮 facts 库现算，确定性、可复算）；
  4. score≥0.15 入选，topk=6，平分按 clock 稳定排序。
- 阈值校准（先于任何真实调用，依据登记在案）：冻结案例 t5 期望取回最低分 0.2031
  与 t6 噪声最高分 0.1069 之间取 0.15，两侧余量 ≥1.35×。

## 2. 来源追踪（四态：已存储→被检索→进入请求→被回复采用）

- 机制每轮追加 `_sandbox/retrieval_trace.jsonl`：
  `facts_stored`（已存储）/ `retrieval.facts_scored`（被检索：score、selected、
  filtered_reason、共享内容字）/ `injected`（进入请求：scene_chain 事实 id、
  **ongoing 全量注入照旧并显式标注**、topic）。追踪不含 gold/目标清单，
  不注入模型请求；不入快照（branch_done sandbox_tree 散列仍覆盖）。
- 第四态"被回复采用"由 `tools/retr_report.py` 离线复算，规则预登记：
  可发送文本出现事实内容字 **bigram**（相邻两字共现）即记采用——不要求逐字复述。
- **ongoing 掩盖效应确认**：父版本 dev16 中，ongoing 全量注入 4/4 携带过敏信息，
  而 facts 漏检 0/4——"已存储但未被检索"被 ongoing 通道掩盖。新候选不删 ongoing
  （避免制造优势），追踪使两条通道各自可见，对照后量化回复层差异。
- 父版本分支无追踪文件（同 run 内父/子产出可区分，C7 断言）。
