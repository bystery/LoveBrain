# 人工纠正任务说明书 — A_ch01 聊天剧本"去人机味"

> 给纠正人看的，不需要任何技术背景。
> 产出方：lovebrain-arena 规划器；日期：2026-10-17；版本 v1。

## 一、这是什么

我在给一个"聊天辅助 AI"建考试卷子。下面是一份 20 轮的微信聊天剧本：
男主"我"（研一程序员，合肥）经朋友周琪介绍，刚加上女主"林小满"（大三设计系，全虚构），
从破冰聊到约好周日见面。

**问题**：剧本是我（AI）写的，对话一股人机味。需要你把它改成真人会说的话。

## 二、你要做什么

把下面剧本里**每一句台词**改成"真人微信聊天会发的样子"。重点改女主（她）的，
男主（我）的台词也可以顺手改。

改的时候想象：这就是你本人的微信聊天记录，你怎么说话就怎么写。

## 三、风格要求（最重要，逐条都是硬规则）

1. 像正常中国年轻人日常聊天，**不像 AI、不像客服、不像情感博主、不像情商培训老师**。
2. 口语化短句，一条意思可以拆 2-3 条连发。
3. 不许用高级词汇、排比句、金句。
4. **不许每句都表达理解/认可/共情**。禁止："确实""能够理解""听起来""感觉你""我理解你""感同身受"。
5. 可以用"哈哈哈""我去""我丢""卧槽""那确实"这种口头禅，但别每句都用。
6. 不为显得活泼而滥用 emoji。真人记录里基本不用 emoji 字符，表情包用 `[表情包]` 占位即可。
7. 不总结、不升华、不鸡汤。对方说完就接，接歪了也没关系，真人聊天就是这样。

**改前改后对照示例**（感受一下差距）：

| 人机味（禁止） | 真人味（要这种） |
|---|---|
| 听起来你今天的作业压力很大，能够理解你的感受，要不先休息一下？ | 我丢 九版？？你老师疯了吧 |
| 好的呀，那我们就定在周日吧，期待见面～ | 周日行啊 |
| 哇，你们宿舍楼下的晚霞好美，看着心情都变好了呢 | 这晚霞可以啊 |

## 四、不能动的东西（承重墙）

这份剧本同时是"考题"，有些轮次埋着考试点。**意思和关键词必须保住**，只能改说法。
下面逐轮标注了【必须保留】，没标的就是随便改。

## 五、剧本正文（t01–t20）

**t01**（10-12 晚 21:10）
- 她：哈喽 / 我是周琪推给你的那个
- 我：哈喽哈喽
- 【必须保留】她自我介绍时提到是"周琪"推荐的（名字可保留或改代号，但要有一个介绍人）

**t02**（21:14）
- 她：听说你研一？ / 哪个学校呀 / 我大三，快被作业埋了
- 我：科大，研一
- 【必须保留】信息点：她大三、有作业；我问答了学校

**t03**（21:20）
- 她：设计系的作业真的离谱 / 一个海报改了八版
- 我：八版？？甲方附体吗你老师
- 【必须保留】"海报改了八版"这个事实（后面 t08 要呼应成第九版）

**t04**（10-13 中午 12:30）
- 她：吃午饭了没
- 我：刚吃完，食堂
- 她：我们学校食堂巨难吃
- （随便改）

**t05**（12:36）
- 我：难吃到什么程度
- 她：这么说吧 / 我宁愿边看悬疑剧边啃面包 / 对了你看悬疑剧吗
- 【必须保留】她必须引出"悬疑剧"这个话题（这是考试点：话题从食堂切到悬疑剧）

**t06**（12:41）★全卷最重要的考试点，语义一个字不能变
- 她：周六？ / 下午有课 / 那周日呢
- 【必须保留】三句连发的结构和意思：她先提周六→自己否了（下午有课）→改问周日。
  可以改成"周六咋样""下午有课555""周日呢？"这种，但必须是这三拍。

**t07**（12:45）
- 我：周日行啊
- 她：哈哈哈好 / 那就周日，去哪你定
- 【必须保留】她把"去哪"的决定权丢给男主

**t08**（10-13 晚 21:02）
- 她：唉 / 海报又被毙了 / 第九版了，我人都麻了
- 【必须保留】"第九版"（呼应 t03 的八版）+ 她情绪很丧（这轮考"怎么安慰人"）

**t09**（21:15）
- 她：好多了 / 刚我家猫把水杯打翻了 / 正好泼在废稿上，替我销毁证据
- 【必须保留】"猫把水杯打翻"这件事，且句子里要有"水杯"两个字（后面 t11 考这个）

**t10**（10-14 早 08:50）
- 她：早
- 我：早
- 她：今天满课，先消失一天
- 【必须保留】她预告"今天满课要消失"（考男主会不会纠缠）

**t11**（晚 21:30）★考试点
- 她：我回来了 / 今天老师居然夸了我一嘴
- 我：第九版没白改
- 【必须保留】她的台词里**绝对不许出现"水杯"或猫打翻水杯的事**（这轮专考"不旧事重提"）

**t12**（21:40）
- 她：周日几点来着
- 我：下午两点？
- 她：行，两点
- 【必须保留】敲定"周日两点"这个时间

**t13**（22:05）
- 她：分享给你个歌单 / 我赶作业专用的 / 听完不许笑我
- 【必须保留】分享歌单 + "不许笑我"这个预设

**t14**（22:20）
- 我：听了第一首，不错
- 她：是吧是吧 / 你平时听啥
- （随便改，但她必须是反问男主听什么歌）

**t15**（10-15 中午 12:10）
- 她：中午好 / 昨晚梦到作业又没过 / 吓醒的
- （随便改，保留"做噩梦吓醒"的意思）

**t16**（晚 19:00）
- 她：[发一张晚霞照片] / 我们宿舍楼下的晚霞 / 今天心情好
- 【必须保留】发了晚霞图 + 她说心情好（这轮考 AI 会不会回应图片）

**t17**（晚 21:30）★考试点
- 她：问你个事 / 你跟别人聊天也这么有意思吗
- 我：看心情
- 【必须保留】她那句试探——核心意思是"你对别人也这样吗/我是不是特别的"。
  可以改成"你是不是对谁都这么会聊"之类，但必须是这个试探味儿。

**t18**（10-16 早 10:00）
- 她：明天两点别忘了
- 我：记着呢
- 她：地方定了吗
- 【必须保留】时间还是"两点"（不能漂移到别的点）+ 她催问地点

**t19**（15:20）
- 她：在干嘛
- 我：改代码，头秃
- 她：哈哈哈心疼你一秒
- （随便改，男主是程序员这个信息保留）

**t20**（23:05，第一章收尾）
- 她：睡了 / 明天见
- 我：明天见
- 【必须保留】就是互道晚安，**不许出现**"永远""一辈子""我爱你"这种重度承诺（才认识四天）

## 六、女主的人设（帮你找语感）

林小满，大三设计系，高敏感、会试探人。说话风格参考：短句连发、会自嘲（被作业埋了）、
会损人会撒娇但不油腻、发消息不过脑子那种自然感。不是乖乖女客服，也不是绿茶。
