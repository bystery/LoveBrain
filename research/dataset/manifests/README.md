本目录存放 `dataset/` 的**结构层公开件**；与同级 [`synthetic_samples/`](../synthetic_samples/) 共同构成 dataset 域的全部公开面。口径与 [`research/README.md`](../../README.md) §3（dataset 域三口径）一致：

| 口径 | 位置 | 内容 |
| --- | --- | --- |
| 1. 原件（不公开） | 本地私有保留，**不在本仓库** | 真实 KB 快照 5 个目录 / 84 文件 / 735,202 字节：真实聊天导出的知识库快照，含真实姓名、真实对话与健康信息，属"无法安全脱敏"档。**永不出站，含任何脱敏形式。** |
| 2. 结构摘要（本目录） | [STRUCTURAL-SUMMARY.md](STRUCTURAL-SUMMARY.md) | 19 种文件名矩阵、目录树模板、字段/章节骨架、行数与字节量统计、机制文件键结构、合成样本生成规范。**零原件正文、零真实姓名、零对话。** |
| 3. 合成样本（同级目录） | [`synthetic_samples/`](../synthetic_samples/) | 5 套合成 KB（`synthetic_kb_01`–`synthetic_kb_05`，共 92 文件）。生成方式 = **AI 原生子代理学习真实 KB 的结构、话题分布与对话格式后生成**——结构相似、内容全假；零真实姓名残留、零真实对话片段、零可还原特征；三层 synthetic 标记（库级 `SYNTHETIC_MANIFEST.json` / kb.json 键 / 每文件首行注释）+ 占位符词典；落树前强制隐私扫描通过。 |

## 原件不公开声明

原件为真实聊天导出的知识库快照（含真实姓名、逐字对话、健康信息），无法安全脱敏。按 2026-11-12 迁移决策三：**原件 100% 不进公开仓库（含脱敏形式），本地保留；公开形式 = 结构摘要 + 合成替代样本。** 本仓库 `dataset/` 下任何位置不存在原件或脱敏原件副本；逐文件敏感性判定与审查明细为内部记录，不随本仓库公开。
