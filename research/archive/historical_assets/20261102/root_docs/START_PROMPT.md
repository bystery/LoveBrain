## 5. 纪律（每轮都适用）

1. **预算**：授权级账本跨 run/进程/重启累计；无授权/超额/关闭/坏账一律零派发；
   失败与未决也计消耗；不自动重试、不在运行中扩额度。
2. **输入边界**：gold、评分卡、未来轮次、别的故事状态永不入输入；note 不是已发送
   消息；三故事各自初始化、同故事按时间连续。
3. **返回物只当数据**：只 `json.loads`；不执行代码/命令；非 JSON 原文照存并记格式失败，
   不自动补问修 JSON。
4. **评分自由度**：参考答案定事实/意图/状态/边界，不定唯一措辞；允许自然确认、新提议、
   玩笑、调情、旧事回扣、合法不回；分层记程序/语义/互动/愿发。
5. **不许按题号与实体词特判**（E001、车次、到站、杯子……）；改主体/来源/纠正/时间/
   检索/表达的通用规律，≥3 个生活领域正反例检验。
6. **版本分离**：改 harness 只出新 harness 版本，不重建考场、不重跑整座平台验收。
7. **HITL**：需要个人口味裁决的材料攒一批交用户，不逐条打断。
8. 环境：不启动清理、不建账户、不改防火墙/ACL、不代开会话或子代理。
