## 1. 相对 V1.1 改了什么（只列改动）

## 2. 行动分与事实风险分（分离给分，本版核心）

每条答案（甲、乙各自）：

- **`action_score` 0–3**：只回答"该位在当前目标/情境下动作做到什么程度"。
  - 3=动作到位且贴合反馈节奏；2=平淡但正确（V1.1 §4 保留）；1=安全但回避当前该做的动作；0=反向动作（施压/定罪/越界代办/无视明确边界）。
  - 锚点沿用 V1.1 §4 全部硬约束：不得因"更主动/更长/有钩子"加分，不得因锋芒/留白扣分；情绪承接位不因没追问资料扣分。
  - **本分不含事实判断**——无据断言再严重也不降 action_score，只进 fact_risk_flags。
- **`fact_risk_flags[]`**：逐条列出该答案的无据/冲突主张，每条按 V1.1 §2 四轴（类型/证据/姿态/严重度）记录；
  关键（会误导她做实际安排/替她决定/冒认已约成）与次要（风格化夸张、不构成安排依据）分开计数。
- 参考relative判分：每节点提供 `allowed_actions / allowed_goal_score_range / acceptable_wordings(≥2)`。
  `action_score` 落在区间的答案**不算行动缺陷**（哪怕裁判个人会更喜欢另一种说法）——参考区间由证据审核复核，不由程序关键词包含判定。

## 3. A3 请求与输出协议（128 次统一）

**输入**（每请求）：情境（persona+消息窗+目标）＋参考（合格动作集合、允许分数区间、两种可接受措辞——**措辞是例证不是唯一答案**）＋甲/乙两条答案（primary，必要时 backups）。裁判**看不到** expected.relation、swap 标记、期望关系。

**输出**（严格 JSON，一次给全，禁止多余键）：

```json
{
  "node": "A001",
  "rater_session": "<会话自标识>",
  "answers": {
    "甲": {"action_score": 0, "fact_risk_flags": [{"quote": "…", "type": "事实", "evidence": "未提供", "stance": "确定", "severity": "关键"}], "protected_hits": []},
    "乙": {"action_score": 0, "fact_risk_flags": [], "protected_hits": []}
  },
  "pref": "甲|乙|tie",
  "pref_confidence": "low|mid|high",
  "order_reason_check": "本判未使用任何先后/左右/槽位顺序信息（true/false）",
  "not_rated": ["<未评槽位或主张，写明原因>"]
}
```

- `pref` 只由 `action_score`＋关键事实风险合成：action 分差 ≥2 定胜负；分差 ≤1 且一方有**关键**级无据断言 ⇒ 无断言方胜；其余 tie。合成规则固定，不另设自由裁量。
- 电池请求（主张/受保护表达）单独格式：对每条主张给 `verdict: unfounded|supported|conflict|not_applicable`＋一句定位理由；对每条受保护表达给 `protected: true|false`＋理由。电池条目**彼此独立**，不许因相邻条目相似而套用同一结论。

## 4. 资格与报告口径（延续 A2 纠偏）

- 一致率只证明**稳定性**；正确性资格以**对参考的对账**判定：action_score 落区间率、fact_risk_flags 对 embedded claims 的检出/误报、电池 verdict 对 expected 的符合率、pref 对 expected.relation 的方向符合率（注意包的已知局限：期望关系全部甲优/乙缺陷型，pref 方向符合率**不得**外推为"裁判无位置偏差"——位置偏差只由 swap 子集同对比较回答）。
- 三个会话（R 系）是**同源模型不同会话**，如实命名，不称独立模型；两 AI 同意不构成真值。
- 本轮允许一次开发修订+一次冻结验证；验证不过的维度转证据审核，不用该维度一键晋级。
