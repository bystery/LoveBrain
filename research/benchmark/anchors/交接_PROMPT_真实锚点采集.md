## 数据格式（已勘察，按此解析）
zip 解压后看这几个文件：memory/raw_chat.md、memory/raw_topic.md（其他文件里若也出现「最终回复」模式则一并处理）。关键格式：

```

她：小樊我好爱你 ……
她：以后你也要好好的
我（最终回复：方案B-渣男）：行。既然你决定了，我不拦。……
```

raw_topic.md 里还有话题标题（如 `# [2026-07-26 15:08] 调情确认`）和 `### … 对话记录` 分节。

解析规则：
1. 每个「我（最终回复：方案X-风格名）：回复文本」= 一条待评条目（冒号可能是全角，风格名取"方案X-"和冒号之间，如"渣男/推荐/调皮"）；
2. 上下文 = 同一块里该条目之前的「她：」「我：」行（全角冒号兼容），最多取前面 8 行；带时间戳；raw_topic.md 里的话题标题（如"调情确认"）作为场景标签一并提取；
3. 同一回复可能因 raw_chat.md 和 raw_topic.md 重复记录，按（时间戳+回复文本）去重；
4. 全量提取不抽样，最后报告：共多少条、风格分布、每来源文件多少条。

## HTML 要求（保存到 D:\lovebrain-arena\benchmark\anchors\real\REPLAY_PICKER.html，目录没有就建）
- 单文件：全部数据内嵌 `<script>` 的 JSON 里，原生 JS，无网络请求、无外部依赖，双击即用；
- 每条一张卡片：时间戳 + 风格徽章 + 话题标签（有则显示）→ 上下文对话（灰色小字，超过 6 行折叠可展开，「她：」「我：」前缀保留）→ 当时的回复大字突出；
- 每张卡片只有一个勾选框：勾上 = "当时这个写得好"，不勾 = 不好，默认不勾，勾选态视觉明显；
- 每张卡片附一个可选文本框「备注（可不填）」；
- 任何勾选/输入立即自动保存到 localStorage（key: replay_picker_v1），刷新关闭不丢；顶部显示「已勾选 x / 总数 n」；
- 顶部工具栏：筛选（全部/已勾选/未勾选）、按风格筛选、「清空全部勾选」（需二次确认）；
- 「导出 JSON」按钮 → 下载 anchors_selected.json，只包含勾选的条目，schema 严格如下：

```json

  "source": "<zip名>",
  "exported_at": "<ISO时间>",

  ]
}
```
