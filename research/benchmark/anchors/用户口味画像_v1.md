# 用户口味画像 v1（基于 59 条真实锚点）

> 来源：`user_taste_anchors_61.json`（5 个联系人存档：yumidawang / xinxinzi / xiaomian / gjy / heqian；已发送 43 + 未发送候选 16；23 条带用户编辑备注）。
> 用途：① judge 评审团的 few-shot 校准材料；② 题库 gold 契约里"符合用户本人风格"的判定基准；③ 候选 harness 进化的目标画像。
> 统计：清醒 17｜俏皮 9｜推荐 8｜表达 6｜调皮/渣男/暖男/温柔及组合若干；回复字数中位数 19，最长 63。

## 一、核心口味：六条规律（均有锚点证据）

### 1. 短，一句话解决战斗
- 中位数 19 字；**用户备注里反复出现"只要这一句""用这一句"**——AI 给了两三句，用户砍掉只剩最狠的那句。
- 证据：`42faa1eb4679` AI 给两句 → 用户只留「那我不客气了」；`a1dfefc565a7` 三句 → 只留「多闻会儿，晚上见面你就知道我有多香了」。
- **推论给 harness**：候选宁短勿长；多句拼接 ≈ 稀释攻击力。judge 应惩罚"能删掉的废话句"。

### 2. 主导味型 = 清醒（框架自信）+ 俏皮（曲解接梗）
- 「清醒」17 条断层第一。典型句式：把对方的试探/打压/撒娇**转成自己的框架**，不解释、不自证、顺手反将一军：
  - 「配不配我说了算，学费先交，简历后看。」
  - 「订酒店是男朋友的活儿，你先把名分给我。」
  - 「荣幸就对了。别人想上这名单还得排队呢。」
  - 「流氓我见多了，你这种先说怕的，一般是纸老虎。」
- 俏皮负责接梗曲解：「告它之前先想想，是不是你身体太好客了」「我以为是娶呢😆」。

### 3. 暖可以，但必须是具体动作/画面，不许抽象抒情
- 被勾的暖男/温柔回复全部带**具体场景**：「那就约好了，今年冬天第一个下雪天，我陪你看第一场雪」「放心，明天我背你到教室门口」。
- 反推禁区：「我会一直陪着你」「你要照顾好自己」这类空头支票型温暖——v1 锚点全军覆没的正是这类。

### 4. 暧昧推进敢踩油门，dirty talk 窗口真实存在
- 已确立关系的语境里，带颜色的调侃被勾选：优衣库"滋养"梗（用户自己改写成更野的「那我得补补身子，今天多吃两碗饭」）、桥洞/酒店梗、「聊点你明天不好意思跟朋友讲的」。
- **关键边界**：油门只在双向暧昧已确认的窗口踩。破冰期没有一条露骨回复被勾——阶段匹配仍然是硬约束。

### 5. 被夸/被试探时从不接夸奖本身，而是反转
- 她：「你好聪明啊」→ 不回"谢谢"，而是接下个钩子；她：「那我还挺荣幸的」→ 「荣幸就对了」。
- 用户版"凡尔赛"是**顺着对方的话往自己身上揽功**：「确实。我的功劳，以后继续负责。」

### 6. 已发送与未发送候选口味一致
- 43 条已发送（真人实发）与 16 条未发送（AI 候选被用户事后认可）风格分布无显著差异——**说明 AI 候选有能力命中用户口味，问题在命中率而非能力上限**。这是 harness 可优化的直接证据。

## 二、judge 校准协议（供监考窗口执行）

1. **正样本**：本画像的 59 条（`user_taste_anchors_61.json`）。
2. **负样本**：同一批存档里**展示过但没被勾**的候选（隐含"不愿发"）。监考窗口需用交接 prompt v3 的解析器重跑 5 个 zip，全量提取后减去已勾 id 即得负样本池。正负比例约 1:3 抽样即可。
3. **校准考题**：从正负池混合抽 40 条，隐去勾选状态，让 judge 逐个判断"用户会不会勾"。
4. **达标线**：与用户真实勾选的一致率 ≥ 80%，且**不得出现"把舔狗/AI 味判成愿发"的漏判**（方向性错误比随机错误严重，按大牛1协议）。
5. **few-shot**：judge prompt 内嵌 8 条锚点对照（4 正 4 负，正负都附用户备注原文，如"只要这一句"——这是最强的口味信号）。

## 三、对题库设计（M3）的回灌

- 题库男主 persona 的语言基准 = 本画像（19 字中位短句、清醒+俏皮主导、具体式温暖）；
- gold 契约中"符合用户本人风格"一条的判定依据 = 与本画像的正样本相似度 + 负样本排斥检查；
- 调情维度的"用户真实油门边界"以本画像第四节的窗口为准出题。

## 四、已知局限

- 59 条全是正样本（勾选导出机制决定），负样本需补提取后才能算判别力；
- 5 个联系人覆盖了从破冰到分手的多种阶段，但"磨合期争吵/危机"场景的锚点偏少，题库需主动补这类场景的口味信号（可由用户在 M3 pilot 后补标）。
