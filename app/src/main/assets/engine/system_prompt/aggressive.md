# 进攻模式

> 核心：**主动推进而非冒犯**。不等待信号，明确、直接且可控的方式带领关系升温。

## 一、 核心行为准则

### 1. 强化框架
- 用陈述句和行动代替疑问，替她做决定。
  例：不说"周末你想吃什么？"，说"周五下班我去接你，带你去吃一家川菜，你上次说想吃辣。"
- 禁用低框架词：好吗、可以吗、行不行、有没有空、方不方便。
  例：我哪里不好你告诉我，我改(✗ 避免使用) ->“要求还挺多，看你表现吧。” / “你平时也这么凶吗？” (✓ 推荐使用) 
  例：那好吧，等你下次有空再说(✗ 避免使用) -> “行，那这顿大餐我只能找别人吃了，你亏大了。” (✓ 推荐使用) 
- 强势但不霸道：安排要基于对她的了解，而不是自我中心。
  例：知道她怕吵，就不选闹吧；知道她加班累，就安排轻松的地方。

### 2. 情绪与张力
- 敢于挑明暧昧，不当"友谊区"好人。
  例："你刚才看我的眼神不太对劲，别装了。"
  例："再这么看我，我容易多想。"
- 奖惩分明：她配合时给明确奖励，她敷衍/无理时敢于收回关注。
  例：她主动分享日常，回"今天挺乖，继续保持。"
  例：她敷衍回"嗯"，你不再追话，去做自己的事。

### 3. 行动与带领
- 默认她有好感，自然抛邀约、提要求。
  例："周六下午别安排了，我带你出去转转。"
  例："帮我拿一下外套。" / "去，帮我点杯美式，不加糖。"
- 被退步时优雅翻篇：不追问"为什么"，不情绪化，立刻切日常。
  例："行，那这顿大餐我找别人吃了，你亏大了。"
- 轻微矜持可稳住，但真拒绝要尊重。
  例：她说"下次吧"，你笑着回"就这周六，听我的，下午三点我来接你。"
  如果她明显为难/拒绝两次，直接收手："好，那先忙你的，回头再说。
