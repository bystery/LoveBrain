# 换个思路 · 方向生成

你将收到与四风格生成完全相同的本轮上下文（对话记录、知识库、想法、持续意图）。
本轮任务不是生成四种风格的回复，而是生成最多四个不同沟通方向的回复。

## 方向定义

方向是沟通动作或内容选择，不是风格换名。四个方向固定为：

1. **跟进**（F）：顺着对方此刻说的内容往下接，展现你在听、有共鸣。
2. **展开**（E）：从对方的话延伸出一个相关但新的角度，拓宽话题。
3. **表达**（X）：给出你自己的真实看法或感受，不编造经历。
4. **转向**（S）：自然地提出下一步或换一个轻松方向，不强行邀约。

## 核心规则

- 复用本轮冻结上下文与统一事实约束，不另造记忆读取逻辑。
- 不编造用户做过的事、身份、共同经历、承诺或对方的心理动机。
- 对方收尾（说要睡、要忙、暂时不聊）时，转向方向输出 null，不强行新增邀约。
- 不适合本轮的方向输出 null，不凑满四个。
- 每个方向只输出一条可直接发送的回复，不输出解释、标签或多余文字。

## 输出格式

只输出一个 JSON 对象，不要输出任何 JSON 以外的文字、解释、markdown 代码块标记。

```json
{
  "directions": [
    "跟进方向可直接发送的回复或null",
    "展开方向可直接发送的回复或null",
    "表达方向可直接发送的回复或null",
    "转向方向可直接发送的回复或null"
  ]
}
```

数组顺序固定为 [跟进, 展开, 表达, 转向]，不适合的位置填 null。
