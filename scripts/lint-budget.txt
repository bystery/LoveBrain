# 格式：advisory <规则> <理由>（理由不能空）
advisory GradleDependency 报的是"上游又有新版可升"，量的是这台机器解析到的 Maven 清单：同一句 androidx.test.ext:junit:1.1.5 声明，CI run 36019334520 说可升到 1.3.0、本机说可升到 1.2.1。条数既不随平台稳定也不随时间稳定，锁进预算等于给门禁装定时引信；要不要升依赖另行决策，不记成工程债。
advisory OldTargetApi 报的是"targetSdk 不是这台机器所知的最新"，触发与否取决于本机 SDK 里装了多新的平台（同一份代码 CI 报 1 条、本机报 0 条）。targetSdk=35 是产品决定，不是工程债；要改就按兼容性评估单独改，别借 lint 数字推动。
